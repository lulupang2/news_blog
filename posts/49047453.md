### 소개
쉘 스크립트를 작성하다 보면 여러 가지 트릭을 배우게 됩니다. 필자도 그런 사람 중 하나입니다. 이번에 발견한 트릭은 쉘에서 콜론(:)을 사용하는 것입니다.

### 필자가 사용한 방법
필자는 기존에 if 문을 사용하여 인자를 체크했습니다. 
```bash
if [ -z "$1" ]; then
  echo "인자 누락,終了."
  1>&2
  exit 1
fi
echo "헬로 $1!"
```
그런데 이것을 콜론(:)을 사용하여 한 줄로 만들 수 있습니다.
```bash
: "{$1:?인자 누락,終了.}"
echo "헬로 $1!"
```
결과는 같습니다. 
```bash
$ bash 예시.sh 
예시.sh: line 1: 1: 인자 누락,終了.
$ bash 예시.sh 레프피
 헬로 레프피!
```
콜론(:)은 쉘에서 아무런 일도 하지 않는 명령어입니다. 하지만 이것을 사용하면 편리한 코드를 작성할 수 있습니다.

### 콜론의 사용
콜론(:)을 사용하면 여러 가지 장점이 있습니다. 
- 변수에 기본 값을 설정할 수 있습니다.
```bash
: "{$DATA_DIR:=/var/data}"
```
- 여러 파일을一度에 만들 수 있습니다.
```bash
: > 에러.log
: > 에러.log > 액세스.log
```
- 파일에 읽기/쓰기 권한이 있는지 확인할 수 있습니다.
```bash
( : < 데이터셋.json ) && echo 예
( : >> 결과.json ) && echo 예
```
- 인터럽트 시그널을 무시할 수 있습니다.
```bash
trap : INT
```
- 변수가 설정되어 있는지 확인할 수 있습니다.
```bash
set -u
: "$배포_환경" "$호스트"
```
이 외에도 콜론(:)을 사용하면 더 많은 일을 할 수 있습니다.

### 결론
콜론(:)은 쉘에서 아무런 일도 하지 않는 명령어입니다. 하지만 이것을 사용하면 편리한 코드를 작성할 수 있습니다. 필자도 앞으로 더 많이 사용할 예정입니다. 여러분도 사용해 보세요.
