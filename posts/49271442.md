# WCAG 2.2 이해하기
WCAG 2.2는 웹 접근성 가이드라인임. 근데 이 거대한 가이드라인을 읽기 어렵다고 생각해? 그럼 이 문서를 읽어볼 것 추천함. 문서 이름은 **Understanding WCAG 2.2**이지만, 사실 그냥 WCAG 2.2를 이해하게 해주는 문서임. 각 성공 기준에 대해 의도, 누가 이익을 보는지, 어떻게 만족하는지 설명해 줌.

## 왜 이렇게 만들었음?
官方 W3C 문서는 웹 페이지로 제공되는데, 책상에서 보거나 온라인에서 읽을 때 괜찮지만, 이북リ더나 비행기에서 읽거나 전체를 한 번에 검색하고 싶을 때는 안 좋음. 그래서 이 문서를 EPUB와 PDF 형식으로 변환해 봄. 같은 내용지만 다르게 포장한 거임.

##注意事項
* 이건 비공식 형식 변홈. W3C 문서에서 자동으로 생성된 거임. 내용은 같지만 레이아웃만 EPUB와 PDF에 맞게 바뀐 거임. 표준 버전은 아님.
* Understanding 문서는 정보 제공 문서임. WCAG를 만족하기 위해 필요한 건 아니지만, 이해하기 쉬움.
*저작권은 W3C에게 있음. 원본 문서는 W3C 문서 라이선스하에 발행되어 있음. 이 라이선스에서는 원본tribution과 notices를 유지한 채로 복사와 배포를 허용함.
* この文件はその許可の下で提供されています. 저는 내용의 소유권을 주장하지 않음.
*信頼する前に, 공식 W3C 페이지를 확인해 봐야함. 파일은 시간이 지남에 따라 저장소에서 재생성됨. 정확한 소스 커밋은 각 파일 내에 출력됨.
