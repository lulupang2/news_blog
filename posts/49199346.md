# 개발 세계의 쓰라림
개발世界에서Wall이라고 부르는 어려움은 요새는 거의 사라짐. 자동화된工具들이 너무나 잘 발달해서 개발자가 해야 할 일들이 거의 사라져 버림. 이제는 아이디어를 적극적으로 구현하기만 하면 됨. 

##品이란 건 무엇인가
품은 개발에서 가장 중요한 요소임. 개발자는 좋은 코드를 작성하고 싶지만, 어떤 것이 좋은 코드인지 판단하기는 쉽지 않음. 이런 판단력을 품이라고 함. 하지만 요새는 개발 도구가 너무 발달해서,開発자가 좋은 코드를 작성하지 않아도 도구가 알아서 코드를 자동으로 생성해 줌.这样하면 개발자는 코드를 작성하는 데 시간을 쓰지 않아도 되지만, 품을 entwickeln하는 데는 시간을 쓰지 못하게 됨.

##品을 desarrollar하는 방법
품을 développer하는 방법은 매우 어려움. 개발자가 직접 코드를 작성하고, 오류를 수정하고, 다시 작성하는 과정을 여러 번 반복해야 함. 이렇게 하면 개발자가 코드에 대한 감각을 entwickeln할 수 있음. 하지만 요새는 도구가 너무 잘 발달해서, 개발자가 직접 코드를 작성할 필요가 없음.这样하면 개발자는 코드에 대한 감각을 entwickeln하지 못하게 됨.

##결론
요새 개발 세계는 너무 쉬워졌어. 하지만 品는 여전히 매우 중요해. 개발자가 좋은 코드를 작성하고 싶다면, 직접 코드를 작성하고, 오류를 수정하고, 다시 작성하는 과정을 여러 번 반복해야 해.这样하면 개발자가 코드에 대한 감각을 entwickeln할 수 있고, 좋은 코드를 작성할 수 있을 거임. 그리고 개발자는품을 entwickeln하는 데 시간을 쓰는 게 아니라, 코드를 작성하는 데 시간을 쓰면 안 된다는 거임. 코드를 작성하는 건 도구가 할 일이고, 개발자는 품을 entwickeln하는 데 Concentrate해야 한다는 거임. ㅋㄷㅋㄷ
