# Yadda 3.0.0: 인공지능 시대에 맞춘 BDD 
     요즘 개발하는 사람들 보면 인공지능이랑 같이 협력하는 경우가 많음. 그런데 이게 요새 개발 트렌드가 되고 있어. 
     Yadda 3.0.0은 이에 맞춰서 나온 BDD 라이브러리임. 
     ## Yadda 3.0.0의 특징 
     - Node.js 전용 
     - 브라우저 번들링과 CasperJS, PhantomJS, Bower, Component 같은 옛날 기술은 다 뺐음 
     - 테스트_suite를 node:test로 옮김 
     - Biome, lefthook 사용 
     - ES6 문법 사용 
     - Playwright, Puppeteer 예제 추가 
     - TypeScript 정의 추가 
     ## 인공지능과 협력 
     Yadda 3.0.0을 개발할 때 인공지능을 사용해서 작업했음. Claude라는 도구를 썼음. 
     이 도구 때문에 작업 시간을 엄청缩短할 수 있었음. 
     ## BDD의 장점 
     - 요구사항을 普通 언어로 작성해서 도메인을 명확하게 정의할 수 있음 
     - 실행 가능한 명세서라서 개발자뿐만 아니라 다른 사람들도 이해하기 쉽음 
     - 기능 테스트의 추상화 계층으로 사용할 수 있음 
     ## 인공지능과 BDD 
     인공지능이 개발에 협력하는 세상이 되면서 BDD의 эконом성이 바뀌고 있음. 
     실행 가능한 명세서를 만들고 유지 보수하는 Kosten이 줄어 듬. 
     인공지능이 개발을 도와주기 때문에 BDD의 장점을 더 잘 활용할 수 있음. 
     ## 결론 
     Yadda 3.0.0은 이런 인공지능 시대에 맞춘 BDD 라이브러리임. 
     인공지능이 개발에 협력하는 세상이 되면서 BDD의 중요성이 더 커지고 있음.
