### 요약
클라우드에서 쓸 수 있는 공유 메모리 그래프가 나왔대요. 클라우드에 저장된 메모리는 클라우드에서 돌아가는 ai가 기억할 수 있대요. 

### 사용 법
1. 클라우드에 저장하고 싶은 것을 말해요. 예를들면 '이건 저장해라' 라고 하면 클라우드에 저장돼요 ㅋㅋ
2. 저장한 걸 확인할 수 있어요. 클라우드 대시보드에서 저장한 내역을 볼 수 있대요. 
3. 저장한 걸 다른 ai에서 꺼내 쓸 수 있대요. 예를들면 클라우드에서 저장한 걸로 채팅할 수 있대요 ㅋㅋ

### 메모리 그래프
클라우드에서 저장된 메모리는 그래프로 저장돼요. 저장된 메모리를 볼 수 있고 수정할 수도 있대요. 

### 특징
- 클라우드에서 저장된 메모리는 ai가 기억할 수 있대요 ㅋㅋ
- 저장된 메모리는 그래프로 저장돼요. 
- 저장된 메모리를 볼 수 있고 수정할 수도 있대요. 
- 저장된 메모리는 다른 ai에서 꺼내 쓸 수 있대요. 

### 사용 가능 도구
- 클라우드 대시보드
- api
- sdk
- mcp 링크 연결된 클라이언트

### 시작하는 방법
1. 클라우드에 가입해요. 
2. 클라우드 대시보드에서 mcp 링크를 생성해요. 
3. mcp 링크를 클립보드에 복사해요. 
4. 클립보드에 복사된 mcp 링크를 채팅창에 붙여 넣으면 저장할 수 있어요 ㅋㅋ 

### 개인정보 보호
클라우드에서 저장된 메모리는 개인 정보 보호가 철저하대요. 저장된 메모리는 절대로 판매하거나 외부에 공개하지 않대요. 저장된 메모리는 사용자가 언제든지 삭제할 수 있대요.
