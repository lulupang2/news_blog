# Bor v0.8.0 업데이트 내역
 
     Bor v0.8.0이 출시되었음! 이번 버전은 썬더버드, 엣지, 방화벽 존과 같은 3가지 새로운 정책 타입이 추가되었고, 풀 웹 UI 오버홀도 되었어. RBAC도 보강되고, 보안 강화도 했대.
 
     ### 썬더버드 정책 타입
 
     썬더버드를 관리할 수 있는 정책 타입이 추가되었어. 이제 보루 관리되는 썬더버드 정책으로 데스크탑이 관리가 가능해졌음._flatpak 설치도 검출되어서 강제하고, 관리되는 파일은 임의로 편집하면 바로 복구됨.
 
     웹 UI에서는 풀 정책 편집기가 제공되고, 썬더버드 정책 카탈로그도 완전 제공되고 있어. 
 
     ### 엣지 정책 타입
 
     엣지 브라우저용 정책 타입도 추가되었어. 이제 엣지가 설치된 리눅스 데스크탑도 관리가 가능해졌음. 관리되는 정책을 JSON형태로 편집할 수 있고, 설정 미리보기도 제공되고 있어.
 
     ### 방화벽 존 정책 타입
 
     방화벽 존관리 정책 타입도 추가됨. 이제 서비스, 포트, 포워드 포트, 리치 룰, мас커레이드, 인터페이스, 소스, 존 타겟을 모두 관리할 수있음. 방화벽 존 설정도 검증하고,_reload도 자동으로 되고, 관리되는 파일은 모두 보장됨.
 
     ### 보안 강화
 
     이번 버전에는 보안 강화도 많이 되었음. 보안 업데이트가 많이 되었고, 여러가지 보안 취약점도 수정됨. 보안 관련해서는 항상 신경써줘야 하니까 꼭 업데이트 해줘야함.
 
     ### 기타 변경점
 
     이번 업데이트에는 여러 가지 다른 기능도 추가되었음. 이제 노드와 복종성 목록은 서버측에서 페이지네이션하고, 필터링하고, 정렬도 되고, 엑세스빌리티도 개선됨. 이제 접근성 기능들고, 전체적인 사용자 경험도 좋아졌음. 그리고 앞으로 업데이트할 내용도 많이 남아있으니 계속 지켜봐줘
