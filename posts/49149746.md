# 오픈스트리트맵에 기부는 이렇게 어려운 거야?
   Book Corners에선 오픈스트리트맵에서 초기 데이터를 가져왔었음. 그런데 사람들은 새로운 도서관을 제출할 수 있고, 관리자가 검토하고,公開하면 그 데이터를 오픈스트리트맵에 다시 기부할 수 있는 기능을 넣고 싶었어. 
   하지만 그렇게 단순하지 않더라고. 데이터를 기부하려면 관리자 계정 만들고, 기부 계획서를 작성하고, 라이센스 문제 해결하고, 중복 데이터 확인하고... 이런거 생각하고 하면 정신차리고 나면 해가 진다니까 ㅋㅋㅋㅋ 
   오픈스트리트맵에선 악의적으로 데이터를 기부하는 사람들을 막기 위해 이런 복잡한 과정을 거치고, 좋은 데이터만 기부하도록 하는 거야. 
   문제는 Book Corners는 작은 프로젝트인데, 이렇게 많은 일들을 하려면 너무 복잡해짐. 그냥 포기하고, 데이터를 오픈스트리트맵에 기부하는 기능은 넣지 않기로 결정했어. 
   # 결론
   오픈스트리트맵에 데이터 기부하는 건 좋지만, 복잡하고 힘든 일이야. Book Corners는 그냥 포기하고, 다른 기능들을 다듬는데 집중하기로 했다는 이야기야. 
   오픈스트리트맵에 기여하는 건 좋은 일이지만, 책임감 있는 개발자가 되기 위해선 가끔은 포기를 선택해야 한다는 걸 기억해 줘. 이쯤하면 알겠지? ㅋㅋㅋ
