### DDisasm 소개
DDisasm은 애플리케이션의 기계어 코드를 자동으로 역어셈블링 해주는 도구야. 이 도구는 ELF나 PE파일을 분석해서 기계어 코드를 해독하고, 거꾸로 다시 소스 코드로 되돌려주는 거야. 예를 들어, 윈도우즈나 리눅스에서 만들어진 애플리케이션을 분석해서 원래의 소스 코드를 복원할 수 있어.
 
### DDisasm의 특징
* **ELF와 PE 파일 지원**: DDisasm은 ELF와 PE 파일을 지원해서 윈도우즈와 리눅스에서 만들어진 애플리케이션을 분석할 수 있어.
* **x86, ARM, MIPS 아키텍처 지원**: DDisasm은 다양한 아키텍처를 지원해서 많은 종류의 기계어 코드를 분석할 수 있어.
* **GTIRB 중간 표현**: DDisasm은 GTIRB라는 중간 표현을 사용해서 분석된 기계어 코드를 쉽게 분석하고 수정할 수 있어.
* **역어셈블링**: DDisasm은 기계어 코드를 자동으로 역어셈블링 해줘서 원래의 소스 코드를 복원할 수 있어.
 
### DDisasm 사용법
1. **도커 이미지 다운로드**: DDisasm을 사용하려면 도커 이미지를 다운로드해야 해. `docker pull grammatech/ddisasm:latest` 명령어를 사용해서 이미지를 다운로드할 수 있어.
2. **도커 컨테이너 실행**: 도커 이미지를 다운로드했다면, `docker run -v $PWD/examples:/examples -it grammatech/ddisasm:latest` 명령어를 사용해서 컨테이너를 실행할 수 있어.
3. **애플리케이션 분석**: 컨테이너를 실행했다면, `ddisasm` 명령어를 사용해서 애플리케이션을 분석할 수 있어. 예를 들어, `ddisasm ex --ir ex.gtirb` 명령어를 사용해서 `ex` 애플리케이션을 분석하고, GTIRB 중간 표현으로 저장할 수 있어.
4. **GTIRB 중간 표현 수정**: DDisasm은 GTIRB 중간 표현을 수정해서 애플리케이션을 수정할 수 있어. 예를 들어, `gtirb-pprinter` 명령어를 사용해서 GTIRB 중간 표현을 소스 코드로 변환할 수 있어.
 
### 결론
DDisasm은 애플리케이션의 기계어 코드를 자동으로 역어셈블링 해주는 도구야. 이 도구는 다양한 아키텍처와 파일 형식을 지원해서 많은 종류의 애플리케이션을 분석할 수 있어. DDisasm을 사용해서 애플리케이션을 분석하고 수정할 수 있어. ㄹㅇ 대박이야!
