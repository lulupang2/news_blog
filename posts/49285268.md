### 스프레드 시트는 쓰지 말라! 
디랑박사님께서 스프레드 시트를 쓰지 말라는 이유를 설명하는데, 이 이유가 생각보다 간단하잖아? 
스프레드 시트는 데이터 저장소, 논리 기계, プレゼンテ이션 툴 다 한 곳에 있어 looks 좋은데? 
근데 이건 사실 독이 된다는게 디랑박사님의 주장임. 
그는 지난 10-15년간 수십개의 데이터셋을 분석해야했는데, 이건 모두 엑셀 스프레드 시트 형태로 받아왔음. 
엔지니어링 회사에서 이 데이터셋을 생성한 이유는 다양하지만, 대부분은 데이터 분석을 포함해 테이블을 만들기 위함이었음. 
근데 디랑박사님한테는 이게 오히려 더 많은 일을 가중시켰다고 하네. 
원인은? 
1. 분석이 중복되거나, 다른 사람과 작업 시 충돌이 발생할 수 있음. 
2. 일부 데이터는 불일치하거나, 다른 사람과 다를 수 있음. 
3. 일부 데이터를 찾기 위해 많은 스크롤이 필요할 수 있음. 
4. 데이터가 분산되어 있어서, 하나의 파일로 묶어서 작업해야 하는데, 여기에 시간浪費가 발생하는 듯. 
이 외에도 데이터 크기에 제한이 있을 수 있고, 처리하기 어려운 데이터가 있을 수 있음. 
그ذا 이런 문제들 때문에 스프레드 시트가 적합하지 않다고 결론지었 음. 
대신 디랑박사님은 파이썬이나 Pandas와 같은 툴을 사용해 데이터를 처리했고, 이렇게 하면 데이터 작업이 더 효율적이고, 빠르게 할 수 있음을 설명함. 
결론은, 스프레드 시트는 쓰지 말라는 거야 ㅋㅋㅋㅋㅋㅋ
