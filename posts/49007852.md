# C++ Lock-Free 큐 만들기

     ### 개요

     Lock-Free 큐라는 게 있으면 멀티스레드 프로그래밍 할 때 좋을 텐데, 직접 만들면 진짜 개빡セン다 ㅋㅋㅋㅋ

     ### Lock-Free가 뭐임?

     Lock-Free란 간단히 말하면 락을 사용하지 않고 멀티스레드간에 자원을 공유하는 개념임. 락을 사용하지 않으니 동기화 오버헤드가 없어서 개빡센 거임 ㄹㅇ

     ### C++로 Lock-Free 큐 만들기

     C++로 Lock-Free 큐를 만들면 개념부터 직접 구현해야 하는디, 이 부분은 정말 개짜증남... ㅋㅋㅋㅋ
     CAS Compare-And-Swap이라는 명령어를 사용해서 구현하는데, 이 명령어가 뭔지 모르면 진짜 이해하기 개빡셀 거임 ㅋㅋㅋ
     CAS는 두 개의 메모리 위치의 값을比较해서 다른 메모리 위치의 값을 변경하는 명령어임. 이 명령어를 사용해서 큐의 노드를 연결하고, 노드를 제거하는 등의 작업을 할 수 있는 거임.
     
     CAS를 사용하기 위해서는 std::atomic 헤더를 포함하고, atomic변수를 선언해서 사용해야 하는디... 이 부분은 진짜 디테일한 설명이 필요할 거임. 설명하기 좀 빡센 거 같지만, 일단 CAS를 사용해서 노드를 연결하고, 노드를 제거하는 부분을 이해하면 Lock-Free 큐를 만드는건 개쪽팔リ지도 않음 ㅋㅋㅋ
