# 러스트 언어를 처음 다루는데成功한 마크다운 컴파일러 만들기
러스트 언어를 처음써본앤데, 막상 만들어보니까깊은맛이있었음 ㅋㅋㅋㅋ. 

## 컴파일러만들기
컴파일러는 다음과같은 단계로 진행됨:
- `post/` 디렉토리를스캔해서 각 파일스캔
- 각 블록스캔
- 각 인라인 요소스캔
- 중간표현(abstract syntax tree, AST)을 생성
- `.html`로 출력, 템플릿으로 생성

이 컴파일러는 다음과같은 마크다운문법을 지원함:
- 헤딩: `#` ~ `######`
- 단락: 빈줄로 구분
- 코드 블록: ```` 또는 ~~~
- 순서 목록: `- [텍스트]`
- 비순서 목록: `n) [텍스트]` 또는 `n. [텍스트]`
- 블록 쿼트: `> 인용문`
- 인라인 코드: ``코드``
- 인라인 취소선: `~텍스트~`
- 인라인 볼드: `**텍스트**`
- 인라인 이탤릭: `*텍스트*`
- 링크: `[텍스트](URL)`
- 이미지: `![대체 텍스트](URL)`, 이미지 URL은 `static/` 디렉토리를 기준으로 함

컴파일러는 YAML 프론티어 블록으로 시작, `---`로 구분, 다음과같은 정보지원:
- `title`: 게시물 제목, 필수
- `date`: 게시물 날짜, 필수, `YYYY-MM-DD` 형식
- `description`: 게시물 설명, 선택
- `tags`: 게시물 태그, 선택
- `draft`: 게시물 작성 중, 선택

### 예시
`index.html`는 모든 게시물 목록, 페이지네이션 отсутств, 필터링은 상단 검색창으로, 태그로도 필터링 가능
