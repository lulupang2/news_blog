### 구글 오픈 노어지식 포맷 기반 MCP 메모리가 등장했음 ㅋ 
   MCP 메모리 서버는 인공지능 에이전트들이 긴 시간 동안 데이터를 기억할 수 있게 해줌. 
   MCP 메모리는 OKF(Open Knowledge Format)규격에 따라 메모리 파일들을 저장하고 SQLite 인덱싱을 사용해서 빠른 검색이 가능함. 
   ### MCP 메모리 특징 
   * **persistent state**: 인공지능 에이전트들이 세션과 채팅을 넘어서도 데이터를 기억할 수 있음 
   * **OKF 규격 준수**: OKF v0.2 마크다운 문서와 YAML 프론트마터로 메모리 파일을 저장 
   * **高速 검색**: SQLite FTS5를 사용해서 빠른 키워드 검색과 태그 필터링이 가능함 
   ### 시작하는 방법 
   1. 깃허브 리포지토리에서 MCP 메모리를 클론하고 
   2._setup.py를 실행해서 설정을 완료하고 
   3. 인공지능 클라이언트를 설정해서 MCP 메모리를 사용할 수 있음 
   ### MCP 메모리 사용 예시 
   * 인공지능 에이전트가 기억력을 이용해서 데이터를 저장하고 검색할 수 있음 
   * 사용자는 MCP 메모리를 사용해서 인공지능 에이전트의 기억력을 개선할 수 있음 
   ### 결론 
   MCP 메모리는 인공지능 에이전트들의 기억력을 개선할 수 있는 솔루션이며, OKF 규격과 SQLite 인덱싱을 사용해서 빠른 검색이 가능함.
