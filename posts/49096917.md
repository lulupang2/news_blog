### 소개
인터넷에 떠도는 개소리 걸러주는 신박한 AI 에이전트가 떴다! Bullshit Detector 라고 하는 이 에이전트가 하는 일은 유튜브 동영상, 기사, 트윗, pdf 같은 거에서 사실과 거짓을 구분해주는 거임. 
#### 사용법
원하는 에이전트를 선택해서 설치하고, url을 넣으면 해당 url의 내용을 체크해서 사실과 거짓을 구분해줌. 예를 들어 '이거 개소리냐?' oder '이거 사실이냐?' 이런 식으로 묻으면_FACT_CHECKING해 줌.
#### 설치 방법
설치하는 방법은 두 가지가 있음. 첫 번째 방법은 skills.sh 라는 설치 프로그램으로 설치하는 거임. 이 방법은 에이전트를 설치해서自己에 넣는 방식이라서 사용자 맞춤으로 수정할 수 있음. 두 번째 방법은 claude code 플러그인으로 설치하는 거임. 이 방법은 luôn 최신 버전으로 업데이트되니까 좋다고 하는디, claude code 만 지원하는 단점이 있음.
#### 동작 principio
이 에이전트는_fact-checking을 위해서 youtube, tiktok 같은 동영상 사이트의 자막을 가져오는 기능도 가지고 있음. 그리고 동영상에 자막이 없을 경우, whisper 라는 음성 인식 기술을 사용해서 자막을 생성해 줌. 
#### 지원 에이전트
支持하는 에이전트는 claude code, openai codex, chatgpt, open code 등이 있음.
#### 사용 예시
사용 예시는 다음과 같음. 
- '이거 사실이냐? https://youtube.com/...' 
- '이거 개소리냐? https://tiktok.com/...' 
#### ROADMAP 
앞으로의 업데이트 계획을 roadmap 에서 볼 수 있음.compare 기능과 transcribe 기능이 예정되어 있음.
#### 결론 
인터넷에 떠도는 개소리를 걸러주는 이 에이전트가 꽤 유용할 것 같네. 사실이냐 거짓이냐를 Fact-checking해서 알려주는 기능이 있는데, 이 기능을 활용하면 앞으로互联网에서 정보를 검색할 때 더 정확하게 사실을 알 수 있을 거 같음.
