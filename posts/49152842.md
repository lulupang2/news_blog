## 봉사이(Bonsai) UI 라이브러리 소개
   봉사이(Bonsai)란 제이스 스트리트에서 만든 UI 라이브러리로, OCaml로 만들어졌음.
   Elm에 영감을 받아 만들었고 퍼포먼스가 좋다고 함.
   제이스 스트리트에서 거의 모든 웹 애플리케이션을 봉사이로 만들고 있대.
   봉사이는 순수 함수적.state 머신으로 구성되어 있고, 쉽게 컴포지트할 수 있다고 함.

   ### 봉사이를 사용한 컴포넌트 예시
   여기是个 예시 코드가 있음.
   ```ocaml
   module Dice = struct
     let faces = [ "⚀"; "⚁"; "⚂"; "⚃"; "⚄"; "⚅" ] ;;
     let component (graph @ local) =
       (* Components are implemented as purely functional state machines. *)
       let face, set_face = Bonsai.state (List.hd_exn faces) graph in
       (* Components are incrementally rendered, only when the relevant parts of the state change. *)
       let%arr face and set_face in
         {%html|
           <div>
             You rolled a #{face}
             <button style="" on_click=%{fun _ -> let index = Random.int (List.length faces) in set_face (List.nth_exn faces index)} >
               Roll the dice
             </button>
           </div>
         |}
     ;;
   end
   ```
   ### 봉사이의 특징
   *   순수 함수적.state 머신으로 구성되어 있음
   *   쉽게 컴포지트할 수 있음
   *   인크리멘탈 렌더링upported
   *   퍼포먼스가 좋음
   *   OCaml로 만들어졌기 때문에 백엔드와 프론트엔드에서 같은 언어와 타입을 사용할 수 있음

   ## 봉사이를 사용한 테스팅
   봉사이는 강력한 테스팅 기능을 제공함.
   예를 들어, 사용자 인터랙션을 프로그램적으로 조작하고 DOM의 변경을 관찰할 수 있음.

   ### 봉사이를 사용한 테스팅 예시
   ```ocaml
   let%expect_test "shows hello to a specified user" =
     let handle = Handle.create (Result_spec.vdom Fn.id) hello_textbox in
     Handle.show handle;
     [%expect {|
       <div>
         <input oninput> </input>
         <span> hello </span>
       </div>
     |}];
     Handle.input_text handle ~get_vdom:Fn.id ~selector:"input" ~text:"Bob";
     Handle.show_diff handle;
     [%expect {|
       <div>
         <input oninput> </input>
         - <span> hello </span>
         + <span> hello Bob </span>
       </div>
     |}]
   ;;
   ```
   봉사이는 제이스 스트리트에서 실제로 사용하고 있는 라이브러리임.
   퍼포먼스가 좋고, 테스팅 기능이 강력해서, 웹 애플리케이션 개발에 많이 사용될 거라고 생각함.
   봉사이를 사용하면, OCaml로 백엔드와 프론트엔드를同时 개발할 수 있어서, 코드를 더 효율적으로 관리할 수 있을 거임.
   봉사이를 사용하면, 테스팅도 더 쉽고, 빠르게 개발할 수 있을 거 같음.
   봉사이를 사용해서 뭐 이런 웹 애플리케이션 만들어서 취업이나 창업에 이용할 수 있을지도 모를 일이당.
   아 근데, OCaml이랑 Hakklang이랑 비슷한 언어라서, Hakklang으로 개발하는 게 더 빠를 거 같음.
   Hakklang도 OCaml이랑 거의 비슷한 문법이라서, Hakklang으로개발하다가, Hakklang이 안되면 OCaml로 개발하면되잖음?
   Hakklang이랑 OCaml이랑 둘 다 개발할 줄 알면, 취업이나 창업에 이용할 수 있는 언어가 하나 더 추가되는 거임.
   hakklang이랑 ocaml 둘 다 공부해봐야겠당.
