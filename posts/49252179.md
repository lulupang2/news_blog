### H3-메탈로 미니맥스-H3 인퍼런스 최적화하기 
   애플 실리콘용 네이티브 미니맥스-H3 인퍼런스를 제공하는 H3-메탈 프로젝트가 떴다. 이 프로젝트는 결정적인 호스트/모델 메타데이터부터 시작해, Metal 블록 패리티, 프롬프트 인코딩, 프롬프트에서 비디오/오디오로의 변환, 그리고 최초/최종 프레임 조건과 정렬된 레퍼런스까지 시퀀스의 일련의 작동하는 수직 단면으로 구축되고 있어.
   ### 튜토리얼 
   1. 모델 빌드 및 검사
   예제들은 H3-메탈 스냅샷이 ./MiniMax-H3에 있고, FFmpeg와 FFprobe가 PATH에 사용 가능하다고 가정해. 
   ```makefile
   make -j8 
   mkdir -p outputs 
   ./h3 --info -d ./MiniMax-H3 --info 
   ```
   이것은 모델 레이아웃을 확인하고, 모든 가중치나 미디어를 매핑하지 않고 Metal 장치를 선택해. 
   ```
   ./h3 --help 
   ```
   로 전체 CLI 참조를 확인할 수 있어.
   ### 성능 최적화 
   H3-메탈은 여러 가지 성능 최적화 기능을 제공해. 
   - 인코딩 된 레퍼런스 프롬프트와 DiT를 유지하며 대화식 세션을 시작할 수 있어. 
   ```
   ./h3 -d ./MiniMax-H3 --width 512 --height 512 --steps 6 
   ```
   이것은 인터랙티브 세션에서 사용할 수 있는 몇 가지 유용한 명령어가 있어. 
   ```
   !status 
   !seed 
   !seconds 
   !show 
   !save 
   ```
   이것으로 사용자 정의 조건을 추가해. 
   ```
   h3> !first 
   h3> !last 
   ```
   그리고 이것으로 레퍼런스 이미지도 추가할 수 있어. 
   ```
   h3> !ref-image 
   ```
   이것으로 만들어진 비디오는 세션 디렉토리에 저장돼.
   - 다른 컨트롤을 바꿀 때는 하나씩만 바꿔. 
   최초로 모든 레이어를 복원해, 그 다음으로 모든 디노이징 평가를 복원해. 
   ```
   ./h3 --profile -d ./MiniMax-H3 -p "A red fox walks through fresh snow in a pine forest. Medium tracking shot, natural winter light, realistic fur, soft footsteps and wind." --width 512 --height 512 --frames 22 --steps 50 --layers 50 --reuse 1 -o outputs/fox-close.mp4 
   ```
   이것으로 사용자 정의 프레스ет을 추가할 수 있어. 
   ```
   ./h3 --profile -d ./MiniMax-H3 -p "A surfer riding inside a sharp blue ocean wave, one rider and one white board, realistic spray." --width 512 --height 512 --frames 22 --steps 20 --layers 45 --reuse 2 --token-reduction -o outputs/surfer-fast.mp4 
   ```
   이것으로 성능과 품질의 균형을 맞출 수 있어. 
   요컨대, H3-메탈은 애플 실리콘용 미니맥스-H3 인퍼런스 최적화를 제공하는 프로젝트야. 사용자는 여러 가지 성능 최적화 기능을 사용해 볼 수 있고, 이것으로 사용자 정의 프레스ेट을 생성해. 이것은 개발자와 사용자에게 유용한 툴이 될 거야.
