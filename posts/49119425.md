### 간더(Gander)란 무엇인가요?

간더는 안드로이드용 오픈소스 파일 뷰어입니다. pdf, 워드, 엑셀, pptなどの 모든 파일 형식을 지원하며, 인터넷 접근 권한이 없어 개인 정보 보호에 적합합니다.

### 특징

* 모든 파일 형식을 지원합니다.
* 인터넷 접근 권한이 없어 개인 정보 보호에 적합합니다.
* 오프라인에서 작동하므로 인터넷 연결이 필요하지 않습니다.
* 매우軽量하여(약 15MB) 용량이 작습니다.

### 사용 방법

1. 간더를 다운받습니다.
2. 다운받은 파일을 탭합니다.
3. '앱 설치'를 클릭하여 설치합니다.
4. 설치 후 간더를 실행합니다.
5. 열어볼 파일을 선택합니다.

### 기타 기능

* 폴더 탐색 기능이 있어 원하는 폴더를 쉽게 찾을 수 있습니다.
* 최근에 열어본 파일을 확인할 수 있습니다.
* 찾기 기능이 있어 파일 내에서 찾을 수 있습니다.
* 파일을 공유할 수 있습니다.

### 결론

간더는 모든 파일 형식을 지원하는 안드로이드용 오픈소스 파일 뷰어입니다. 인터넷 접근 권한이 없어 개인 정보 보호에 적합하며, 매우 轻量하여 용량이 작습니다. 간단하고 편리한 사용 방법으로 파일을 쉽게 열어볼 수 있습니다.
