# HTML에 버튼 액션 추가하면 디벨로퍼生活 편해질 듯 
   버튼액션이라는 제안이 있는데 HTML에 버튼에 액션과 메소드 속성을 추가하는 거임 
   `<button action="/begin" method="GET">Start</button>` 
   버튼액션은 간단하지만 왜 필요한지는 바로 버튼과 링크의 차이를 이해하면 알 수 있음 
   링크는 목적지를 말하고 버튼은 액션을 말함 
   링크는 사용자가 어디서 열는지 결정할 수 있지만 버튼은 결정할 수 없음 
   버튼은 Middle-Click, Ctrl+Click 등 Context Menu에서 기본적으로 동작 안함 
   버튼은 기본적으로 고정된 컨텍스트 안에서 동작 
   링크는 사용자가 언제든지 복사, 북마크, 공유할 수 있지만 버튼은 그게 안됨 
   버튼은 링크처럼 컨텍스트를 변경할 수 없음 
   **버튼의 개념** 
   버튼은 기본적으로 고정된 컨텍스트 안에서 동작 
   링크는 사용자가 언제든지 복사, 북마크, 공유할 수 있지만 버튼은 그게 안됨 
   # 버튼액션이 필요한 이유 
   버튼액션은 버튼을 통해 네트워크 요청을 보내고 현재 컨텍스트를 갱신하는 제어를 만드는 것 
   버튼액션은 버튼을 통해 상태 전이를 모델링 하는데 유용 
   예를들면 `<button action="/comments/123" method="GET">Cancel</button>` 
   버튼액션은 버튼을 통해 CRUD Lifecycle을模型化하는데 유용 
   버튼액션은 버튼을 통해 리소스를 갱신, 생성, 삭제하는데 유용 
   # 결론 
   버튼액션은 HTML을 더 강력하고 유연하게 만듦 
   버튼액션은 버튼을 통해 다양한 상태 전이를 모델링 하는데 유용 
   버튼액션은 웹 서비스 개발을 더 쉽게 만듦
