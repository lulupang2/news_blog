### Gemma 4 26B-A4B를 위한 오픈소스 엔진
 Turkbo-Fieldfare라는 오픈소스 엔진이 Gemma 4 26B-A4B 모델을 애플 M시리즈 맥에서 돌릴 수 있게 됨. 이 엔진은 Swift와 Metal을 사용해서 만들었음.
 
### Gemma 4 26B-A4B란?
 이 모델은 26 억 개의 파라미터를 갖고 있어. 하지만 이 엔진을 사용하면 모델 전체를 메모리에 로딩할 필요 없이, 필요한 전문가만 스트리밍해서 로딩할 수 있음.这样하면 메모리 사용량을 줄일 수 있고, 8 기가 램만 있는 맥에서도 모델을 돌릴 수 있게 됨.
 
### 사용법
 Turkbo-Fieldfare를 사용하려면 먼저 Git에서 Repository를 Clone하고, Swift Package Manager를 사용해서 빌드해야 함. 그리고 모델을 다운로드하고 설치하기 위해 인터넷 연결이 필요함.
 
### 터미널에서 모델 설치
 Git에서 Repository를 Clone한 후, 터미널에서 다음 명령어를 입력해서 모델을 설치할 수 있음:
```bash
swift run -c release TurboFieldfareRepack 
  --output scratch/gemma4.gturbo 
  --overwrite
```
### 모델 사용
 모델을 설치한 후, 터미널에서 다음 명령어를 입력해서 모델을 사용할 수 있음:
```bash
swift run -c release TurboFieldfareCLI 
  --model scratch/gemma4.gturbo 
  --prompt "The capital of France is"
```
이 명령어를 입력하면, 모델이 프랑스의 수도에 대한 답을 생성할 것임.
 
### 성능
 Gemma 4 26B-A4B 모델은 8 기가 램만 있는 맥에서도 잘 동작함. M2 맥북 에어에서測定한 성능은 약 5.1-6.3 토큰/초임.
