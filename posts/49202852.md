### vLLM은 뭐임?
vLLM은 현재 최고 속도로 처리되는 LLM 시스템의 내부 구조를 분석한 글임. 
여기서는 vLLM의 모든 핵심 구성 요소와 고급 기능에 대해 소개하고, 
vLLM이 어떻게 작동하는지 자세히 설명할 예정임.

### vLLM의 구성 요소
vLLM의 기본 구성 요소는 다음과 같음:
- **LLM 엔진**: vLLM의 핵심으로, 높은 처리 속도를 가능하게 함.
- **프로세서**: 입력 데이터를 처리하여 엔진에 넘겨줌.
- **엔진 코어 클라이언트**: 엔진과 통신하여 요청을 처리함.
- **출력 프로세서**: 처리된 결과를 사용자에게 제공함.

### LLM 엔진
LLM 엔진은 vLLM의核心으로, 높은 처리 속도를 가능하게 함. 
엔진은 다음과 같은 구성 요소로 이루어짐:
- **모델 executor**: 모델을 실행하여 결과를 도출함.
- **스케줄러**: 요청을 처리하는 순서를 결정함.
- **KV 캐시 관리자**: 캐시를 관리하여 효과적인 데이터访问을 가능하게 함.

### generate 함수
generate 함수는 입력된(prompt) 데이터를 처리하여 결과를 도출함. 
이 함수는 다음과 같은 단계로 이루어짐:
1. **입력 유효성 검사**: 입력된 데이터를 확인하여 올바른지 검사함.
2. **요청 생성**: 입력된 데이터를 처리하여 요청을 생성함.
3. **스케줄링**: 요청을 처리하는 순서를 결정함.
4. **전방 처리**: 모델을 실행하여 결과를 도출함.
5. **후처리**: 결과를 처리하여 사용자에게 제공함.

###_SCHEDULER
스케줄러는 요청을 처리하는 순서를 결정하는 역할을 함. 
스케줄러는 다음과 같은 두 가지 유형의 작업을 처리함:
- **prefill 요청**: 입력 데이터를 전부 처리하여 결과를 도출함.
- **decode 요청**: 최근 토큰만 처리하여 결과를 도출함.

vLLM의 스케줄러는 이러한 두 가지 유형의 작업을 혼합하여 처리할 수 있음. 
또한, decode 요청을優先적으로 처리함.
