### 미니맥스 H3: 오픈 웨이트 영상 모델
   ComfyUI에서 새로운 기술 떴다! 미니맥스 H3는 오픈 웨이트를 가진 영상 모델로, 최대 2K 영상을 생성할 수 있고 스테레오 사운드도 내보낼 수 있단다. 이 모델은 컴퓨UI에서 최적화되어 로컬에서 3060 GPU로 실행할 수 있음.
   
   ### 주요 기능
   * 최대 2K 영상 생성
   * 스테레오 사운드支持
   * 컴퓨UI에서 최적화되어 로컬에서 3060 GPU로 실행 가능
   * 오픈 웨이트를 가진 영상 모델
   
   ### 사용 예시
   이 모델을 사용하면, 사용자는 텍스트, 이미지, 영상, 또는 오디오를 입력으로 넣으면, 해당 입력을 기반으로 영상을 생성할 수 있음. 예를 들어, 사용자는 '볼드한 コ믹 북 飾り, 붉고 파란 검은 색调, 밤의 도시'와 같은 프롬프트를 넣으면, 해당하는 영상을 생성할 수 있음.
   
   ### 기술적인 측면
   미니맥스 H3는 컴퓨UI에서 최적화되어 있기 때문에, 로컬에서 3060 GPU로 실행할 수 있음. 이는 모델의 modulation weights를 pruning하고 lookup table로 대체함으로써 달성된 것임. 또한, 모델의 weights는 int8 convrot quantization을 사용하여 효율적으로 저장될 수 있음.
   
   ### 시작하기
   사용자는 컴퓨UI를 최신 버전으로 업데이트 하고, 미니맥스 H3 모델을 다운로드 받은 후, 컴퓨UI에서 모델을 실행할 수 있음. 사용자는 프롬프트를 입력하고, 参考 이미지나 오디오를 추가한 후, 모델을 실행할 수 있음.
