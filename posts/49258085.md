# 소개
ArcadeMaker는 C#로 작성된 심플한 2D 크로스 플랫폼 게임 엔진으로, 자체 프로그래밍 언어(Exp)와 통합 개발 환경(IDE)을搭載하고 있음. 엔진과 IDE는 C#로 작성되었지만, 엔진 내에서 게임을 프로그래밍할 때 사용하는 언어는 C#가 아님. 현재 그래픽과 오디오 백엔드는 MonoGame으로 구동되며, 데스크탑, 모바일, 콘솔로 내보내기 가능함. 웹 지원을 위해 KNI 엔진 구현도 계획 중임.
# 프로젝트 배경
ArcadeMaker는 여러 단계를 걸쳐 몇 년간 개발되었으며, 프로젝트의 각 부분은 개발者の 프로그래밍 경력의 다른 단계에서 작성됨. IDE는 약 3년 전, 개발자의 프로그래밍 실력이 현재와 다르던 시절에 작성됨. Exp 언어는 이후에 작성되었지만, 현재의 코어 엔진과 MonoGame 구현 이전에 작성됨. 초기에 ArcadeMaker는 C# 기반 엔진으로, 사용자가 게임 로직을 직접 C#로 작성하는 구조였음. 프로젝트를 잠시 중단한 후, 개발자는 자체 프로그래밍 언어를 만들고 ArcadeMaker로 돌아와서 구식 C# 스크립팅 계층을 대체하고, 코어 엔진을 언어 주변으로 다시 작성함.
# 계획된 기능
-_MISSING IDE 기능의 엔진 구현-
- KNI 엔진 백엔드 구현을 통한 웹 내보내기 지원-
- Exp 언어의 완전한 안정版 구현-
- drawRect(), deactivateInstancesInRegion(), setRoomWidth() 등 일반적인 게임 함수 구현-
- 모바일, 콘솔 빌드용 크로스 플랫폼 템플릿-
- 문서화, 튜토리얼, 예제 프로젝트-
# 오픈 소스화 이유
개발자는 ArcadeMaker에 대한 열정을 가지고 있지만, 프로젝트에 걸맞은 속도로 개발할 시간이 충분하지 않음. 오픈 소스화를 통해 다른 개발자들이 엔진을 실험하고, 언어와 툴링을 개선하며, 缺失 기능을 추가하고, 버그를 수정하며, 프로젝트의 미래를 함께 모양作成하여야 한다는데 의미를 두고 있음.
# 빌드 방법
- 저장소를 클론한다.-
- C# IDE(Visual Studio, Rider, VS Code)에서 솔루션을 엽니다.-
- NuGet 패키지를 복원한다.-
- 프로젝트를 빌드한다.-
- IDE 프로젝트를 실행하여 ArcadeMaker를 시작한다.-
# 기부 방법
기부는 모든 종류의 형태로 가능함. 코드 개선, 버그 수정, 문서화, 기능 제안 등 다양한 형태의 기부를 환영함. 풀 리퀘스트를 제출하기 전, 먼저 이슈를 열어 아이디어를 논의한다.
