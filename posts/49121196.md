### 웹 컴포넌트에서 겪는 골치아픈 문제들
요즘 웹 개발에서는 웹 컴포넌트를 쓰는 게 트렌드인데, 근데 여태까지 웹 컴포넌트를 쓰면서 겪는 문제들이 너무 많았음. 레이아웃 시프트, 플래시, 서버사이드 렌더링 지원이 빈약하고, js 의존도가 너무 높고, 리액트나 앵귤러 같은 프레임워크에서 호환성이 너무 떨어지는데다가 접근성도 문제인이 됨.

### Elena 라이브러리
근데 요즘 나오는 Elena 라이브러리에서는 이런 문제들을 모두 해결해줌. 이 라이브러리는 html, css를 먼저 로딩하고, 이후에 js로 인터랙티브한 요소를 추가하는 방식으로 웹 컴포넌트를 구축할 수 있게 해줌. 그래서 레이아웃 시프트 문제가 해결되고, 접근성 också 보장됨. 서버전송 렌더링도 지원해주고, 데카라티브_shadow_dom 같은 기능도 지원해줌.

### 예시
근데 이 Elena 라이브러리가 뭐냐면, 2.6KB의 초경량 라이브러리고, 웹 표준의 native custom element 위에 구축된 거임. 그래서 프레임워크 호환성도 문제없고, 서버사이드 렌더링에도 문제가 없고, 레이아웃 시프트도 없고, 접근성도 보장되고. 그리고 데카라티브_shadow_dom도 지원해서, 보안적인 측면에서도 안전함.

### 마치면서
