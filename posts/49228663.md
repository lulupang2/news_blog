### 마이크로소프트 워드 1.1a 네이티브 x64 포팅 프로젝트 ###

마이크로소프트 워드 1.1a, 코드네임은 Opus였음. 이 프로젝트는 이 옛날 워드를 64비트로 포팅한 결과임. 원본 워드 소스와 리소스를 현대적인 16비트 어셈블리, 세그먼트 메모리, 윈16 플랫폼 경계를 대체하는 것과 함께 빌드한 거임.

결과물은 원본 워드 앱이고 유저 경험은 64비트 윈도우 실행파일로 실행됨. 이건 에뮬레이터나 현대적인 에디터 컨트롤을 사용한 리 IMPLEMENTATION이 아님.

### 요구사항 ###

* 64비트 윈도우
* 데스크탑 개발용 C++가 포함된 비주얼 스튜디오 2022
* 윈도우 10 hoặc 윈도우 11 SDK, 비주얼 스튜디오를 통해 설치됨
* CMake 3.25 또는 최신버전
* 파워셸

### 빌드하고 실행하기 ###

리포지토리를 클론하고, 포함된 CMake 프리셋을 구성하고, 파워셸에서 빌드하기:
```powershell
 git clone https://github.com/jmarshall23/msword.git
 Set-Location msword\src
 cmake --preset x64-debug
 cmake --build --preset x64-debug & ..\bin\WORD1.exe
```

옵티마이즈된 빌드를 사용하려면 릴리즈 프리셋을 사용하면 됨:
```powershell
cmake --preset x64-release
 cmake --build --preset x64-release & ..\bin\WORD1.exe
```

プリ셋은 비주얼 스튜디오 2022 x64 제네레이터를 사용함. 구성된 솔루션은 직접 out\MicrosoftWordX64Port.sln에서 열 수 있음. WORD1을 시작 프로젝트로 사용하면 됨.

### 테스트 ###

리포지토리 루트에서 전체 디버그 테스트 세트를 실행:
```powershell
 ctest --test-dir .\out -C Debug --output-on-failure
```

릴리즈 빌드의 경우 디버그를 릴리즈로 대체하면 됨.

이 테스트 스위트는 포팅된 x64 런타임, 원본 워드 데이터 구조, 명령 테이블, 프로세스 시작, 자동화된 UI 워크플로우를 포함한 타이핑, 선택, 포매팅, 다이얼로그, 저장 등을 커버함.

### 프로젝트 레이아웃 ###

경로 | 목적
-----|----
src/Opus/ | 원본 마이크로소프트 워드/오퍼스 애플리케이션 소스와 리소스
src/OpusEtAl/ | 원본 지원 툴, 라이브러리, 빌드 입력
src/OpusProg/ | 역사적 프로그램 문서
src/port/original/ | x64 호환성 레이어, 번역 루틴, 테스트
src/port/tools/ | 역사적 빌드 툴의 네이티브 대체
src/cmake/ | 리소스와 소스 생성 도우미
out/ | CMake 캐시와 생성된 비주얼 스튜디오 솔루션 빌드
build/ | 중간 툴, 테스트, 프로브, PDB, 다이아그노스틱
bin/ | 최종 실행파일과 런타임 파일

out, build, bin은 구성과 컴파일过程에서 로컬로 생성됨.

### 포팅 방법 ###

원본 C와 리소스 파일이 가장 중요한 구현임. 포팅에선 플랫폼 작업만 추가함. 16비트 x86 어셈블리 엔트리 포인트를 고정폭 C 또는 C++로 번역함. 세그먼트와 더블-인다이렉트 메모리 핸들은 x64-세이프 네이티브 런타임에 매핑함. 윈16-스펙정적인 시작, 메시징, 그래픽스, 파일, 리소스 동작을 최신 윈32 API에 적응시킴. 원본 명령, 다이얼로그, 커서, 비트맵, 기타 생성된 에셋을 네이티브 호스트 툴에 의해 CMake 그래프의 일부로 재구성함. 유닛, 런타임, 스모크, UI 테스트는 원본 알고리즘과 애플리케이션 동작과 호환성을 지키기 위해 가드됨. CMake는 레거시 어셈블리 트리를 인벤토리하지만 네이티브 타겟을 컴파일하지 않음. 역사적 구현은 레퍼런스로 남아있으며, 전송된 코드는 모두 AMD64에 유효함.

### 유용한 대상 ###

대상 | 설명
-----|----
WORD1 | 네이티브 x64 마이크로소프트 워드 실행파일
opus_original_engine | 원본 워드 애플리케이션 엔진, x64로 컴파일됨
opus_x64_runtime | 네이티브 런타임과 번역된 어셈블리 동작
opus_word1_ui_test | 자동화된 엔드-투-엔드 UI 테스트 드라이버
legacy_sources | IDE에서 보이는 원본 어셈블리 레퍼런스 컬렉션

특정 대상을 빌드하려면:
```powershell
 cmake --build --preset x64-debug --target WORD1
```

### 기여 ###

변경은 원본 워드 동작을 보존해야 하며, 모든 네이티브 인터페이스는 포인터-폭 안전해야 함. 역사적 루틴의 소스-등가 번역을 선호하고, 윈도우 API 적응은 포팅 경계에서 분리하고, 새로 번역된 동작에 대한 테스트를 추가하면됨.

### 저작권 ###

역사적 소스 파일에는 원본 마이크로소프트와 제3자 저작권 표시에 유지됨. 이 리포지토리에 현재 상위권 라이선스 파일은 포함되지 않음. 소스나 바이너리를 재배포하기 전에 적용되는 권리를 검토하기 바란다.
