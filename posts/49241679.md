> **🔗 원문 보러가기:** [Meta Muse Glimmer – open weights 30B local coding model](https://research.meta.ai/blog/introducing-muse-glimmer-open-agentic-model)

meta가 만든 ai 모델 무스 글리머 나왔음. 이 모델은 로컬에서 돌려도 된다고 함. 용량도 적어서 맥이나_pc에서 gpu 하나로도 돌아감. 
   meta.superintelligence.labs에서 만든 모델인데, 모델 가중치를 오픈소스로 공개 중. 
   무스 글리머는 항상 켜져 있는 로컬 에이전트 워크플로우 최적화 모델이라고 하네. 
   로컬 에이전트, 함수 호출, 로컬 코딩, llm-아-판단 평가까지 가능하다고 하네.
   foundation 모델들은 이미 기초 능력 다 개발함. 하지만 여전히 클라우드 인프라, 네트워크 접근 필요함. 로컬에서 모델 돌리면 인터넷 없이도 ai 사용 가능.
   오픈소스 커뮤니티에서 작은 모델들을 효과적으로 훈련 시키면 충분히 기존 모델 성능 따라갈 수 있다고 함. 무스 글리머는 이런 로컬 사용 사례를 위해 최적화 됐다고 하네.
   개발자 문서도 제공하니까, 직접 에이전트 만들어서 돌려볼 수 있으려나? 
   llama.cpp, MLX, ExecuTorch도 지원할 거라고 하니까, 이 모델은 개발자들이 사용하기 좋을 것 같당.
   how we trained 무스 글리머 보니까, pre-training, mid-training, post-training 같은 단계로 모델을 훈련 시킴. 
   agentic task completion, reliable tool use, multi-step reasoning, failure recovery, multimodal input and reasoning 등 다양한 사용 사례 지원하는 모델이라고 하네.
   scaffold compatibility, controllable effort, multilingual도 지원하는 모델이라고 하네.
   100개가 넘는 언어에서 데이터로 훈련 시켰다고 하네.
   Gemma4-31B, Qwen3.6-27B 같은 모델과 비교해도, 무스 글리머는 작은 모델치고 성능이 강력하다고 하네.
   로컬에서 모델을 돌리려면 속도가 중요하니까, quantization 기술 사용해서 모델의 크기를 줄였다고 하네.
   full precision에서 30억 파라미터 모델을 돌리려면 55GB가량의 메모리가 필요하대. 근데 quantization 기술 사용해서 4비트 정밀도로 모델을圧缩해서 20GB 미만으로 모델 크기를 줄이는데 성공함.
   이 모델은 MacBook M4-Max, M5-Max, RTX-5090에서도 돌아감. 
   무스 글리머 모델을 사용하면 로컬에서 fluid conversation, real-time agent interaction이 가능하다고 하네.
   이제 무스 글리머 모델을 다운로드 해서 직접 돌려볼 수 있게 나왔대. 
   ollama, lm studio, unsloth 같은 파트너들도 모델을 지원하고, edge framework도 지원하고, pytorch도 지원한다네.
   amd, arm, dell, intel, nvidia도 모델 최적화를 unterstüt한다고 하네.
   meta ai developer center에서 더 많은 정보를 얻을 수 있다고 하네.
