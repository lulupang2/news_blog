# 스퀘어크 6.1 '바네사' 릴리즈 노트

     스퀘어크 6.1 릴리즈 노트는 스퀘어크 안에서閲覧하기 위해 최적화되어 있으며,たくさんの 인터랙티브 예제들을 포함하고 있기 때문에 스퀘어크 안에서閲覧하는 것을 추천함.

     # 새로운 트리 브라우저

     이번 버전의 하이라이트 중 하나는,새로운 트리 브라우저로 클래스와 카테고리를 구분하여 hierarchical morphs라는 걸로 구분할 수 있어.

     # 오브젝트랜드의 부활

     오브젝트랜드, 즉 '스퀘어크의 세계'가 다시 돌아왔어.이 세계 안에는 스퀘어크의 다양한 기능들이 예제로 담겨있어.

     # 커널 인프라스트럭쳐 관련 변경 사항

     이번 버전에서는 시ミュ레이션, 프로세스 언व인딩, 프로세스 스케쥴링, 클래스 리쉐이핑과 관련된 커널 인프라스트럭쳐 관련 변경 사항들과 버그 수정들이 포함되어 있음.

     # 기타 개선 사항

     이외에도 툴셋과 사용자 인터페이스 관련하여 코드를 분석하고 디버깅하고 프로파일링하고 버전 관리를 할 수 있는 다양한 기능들이 추가되어 있고 개선됨.
     # 릴리즈 노트에 관해 말할 것 같으면,
     이 릴리즈 노트에서 자세한 변경 사항들에 관해 설명하고 있는데, 주요 Deprecated와 Known Issues, Compatibility Notes등이 포함되어 있음.
