-agent-manager: 이제 AI 코딩 에이전트 관리하는게 너무 쉬워짐 ㅋㅋㅋ
====================================================

.agent-manager는 Claude Code, Codex, OpenCode, Grok 같은 유명한 AI 코딩 에이전트들을 한 곳에서 관리할 수 있는 툴 임. 이제 각 에이전트를 따로따로 관리할 필요 없이, 하나의 터미널 창에서 필요한 모든 작업을 수행할 수 있음. 예를 들어, 여러 개의 에이전트를 한 번에 실행시키고, 각각의 상태를 실시간으로 모니터링할 수 있어. 
에이전트가 하는 작업을 하나의 목록에서 확인할 수 있고, 작업에 대한 상태를 한눈에 확인할 수 있음. 또한 에이전트를 바로 실행할 수 있고, 에이전트의 상태를 확인할 수 있는 목록에서 상태를 실시간으로 갱신할 수 있음. 
에이전트가 상태를 알려주고 있지만 실제로 어떤 작업을 하고 있는지 바로 알기 어려울 때도 있음. agent-manager는 이런 경우에도 도움이 줌. 에이전트의 상태를 확인하고, 어떤 작업을 하는지 바로 알 수 있게 해줌. 
이外에도 다양한 편의 기능들이 있어. 예를 들어, 에이전트가 작업한 내용을 바로 확인할 수 있고, 다른 에이전트와의 비교도 가능함. 또한 에이전트가 작업하는 디렉토리를 바로 열어볼 수 있고, 에이전트의 설정을 변경할 수도 있음.
agent-manager를 사용하면 AI 코딩 에이전트를 더 효율적으로 관리할 수 있어. 예를 들어, 에이전트를 여러 개 실행시키고, 각각의 상태를 확인할 수 있으므로, 더 많은 작업을 동시에 처리할 수 있음. 또한 에이전트의 상태를 실시간으로 확인할 수 있으므로, 문제가 발생하면 바로 대응할 수 있음.
agent-manager는 다양한 에이전트를 지원함. Claude Code, Codex, OpenCode, Grok 등 인기 있는 에이전트들을 모두 지원하고, 其他 에이전트들도 쉽게 추가할 수 있음. 
agent-manager를 사용하면 AI 코딩 에이전트를 더 쉽게 관리할 수 있어. 에이전트의 상태를 확인하고, 작업을 관리하고, 설정을 변경할 수 있으므로, 더 많은 작업을 효율적으로 처리할 수 있음. 
## 설치 방법
agent-manager를 설치하는 방법은 매우 간단함. Homebrew나 Go를 사용하여 쉽게 설치할 수 있음.
```bash
brew install yoanwai/tap/agent-manager
```
혹은
```bash
go install github.com/YoanWai/agent-manager@latest
```
설치가 완료되면, 터미널 창에서 agent-manager 명령어를 실행하여 사용할 수 있음.
## 사용 방법
agent-manager를 사용하는 방법은 매우 간단함. 터미널 창에서 agent-manager 명령어를 실행하고, 에이전트를 선택하여 실행하면 됨.
```bash
agent-manager
```
에이전트를 실행하면, agent-manager는 에이전트의 상태를 실시간으로 갱신하고, 목록에서 상태를 확인할 수 있음. 에이전트가 작업한 내용을 확인하고, 다른 에이전트와의 비교도 가능함.
## 설정
agent-manager의 설정은 매우 간단함. 설정 파일을 편집하여 에이전트의 설정을 변경할 수 있음.
```bash
agent-manager config
```
설정 파일을 편집하여 에이전트의 설정을 변경하면, agent-manager가 설정을 적용하여 에이전트를 실행함.
