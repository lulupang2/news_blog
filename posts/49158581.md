# 클라우드플레어, 언어 모델 띄우는 기술 공개 
클라우드플레어는 Workers AI가 Kimi와 GLM같은 대형 언어 모델을 효율적으로 처리하는 cách을 공개했어. 
원래 큰 언어 모델들은 GPU 메모리 제약 때문에 요청을 효율적으로 처리하기 어려웠음. 
이 기술로 KV 캐시를 8비트에서 4비트로 quantization하고 모델의 가중치를 8비트에서 4비트로 축소할 수 있어. 
이렇게 하면 GPU 메모리를 더 효율적으로 사용할 수 있고 더 많은 요청을 처리할 수 있어. 
아니 근데 KV 캐시를 quantization하면 어떻게 더 효율적으로 요청을 처리할 수 있냐고?? 
원래 KV 캐시는 모델이 이전에 처리한 토큰들을 저장하는 역할을 해. 
이 캐시를 더 작은 크기로 압축하면 더 많은 요청을同时 처리할 수 있지. 
### KV 캐시 quantization의 효율
원래 KV 캐시는 16비트로 저장돼. 
8비트로 quantization해도 모델의 정확성이 거의 영향을 받지 않아. 
클라우드플레어는 이 효율을 측정해봤어. 
결과는 KV 캐시를 8비트로 quantization하면 요청 처리 속도가 41% 증가하고 비용은 30% 절감될 수 있대. 
### 모델의 가중치 축소
클라우드플레어는 모델의 가중치를 8비트에서 4비트로 축소할 수도 있어. 
이렇게 하면 모델의 크기가 40% giảm하고 GPU 메모리 사용량도 줄어들 수 있대. 
클라우드플레어는 이 효율을 측정해봤어. 
결과는 가중치를 4비트로 축소하면 모델의 정확성이 거의 영향을 받지 않아. 
요청 처리 속도도 20% 증가하고 비용은 15% 절감될 수 있대. 
### 마무리 
클라우드플레어의 이 기술로 더 많은 고객을 더 낮은 비용으로 처리할 수 있게 된대. 
만약 언어 모델을 효율적으로 처리하는 기술에 관심이 있다면 클라우드플레어에서 일해 볼 수도 있지.
