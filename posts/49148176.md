# 버블 메모리란? 
     버블 메모리는 thin film형태의 magnetic 물질을 사용해 작당 작은 크기로 자화된 영역, 즉 버블이나 도메인이라고 부르는 걸 만들어서 하나의 비트를 저장할 수 있게 해주는 비휘발성 메모리라 생각해.
     
     # 버블 메모리 작동 원리 
     버블 메모리는 external magnetic field에 의해 작동하는 거야. magnetic field를 이용해서 bubble을 읽어오고, 쓰고, 지우는 걸 반복함으로써 메모리가 작동하는 거지.
     
     # 버블 메모리의 역사 
     버블 메모리는 1960년대 후반에 시작됐고, 1970년대에 본격적으로 개발되어 많이 쓰이기 시작했어. 하지만 Dram과 같은 semiconductor memory의 등장으로 버블 메모리는 구식이 되는 거지.
     
     # 버블 메모리의 특징 
     버블 메모리는 non-volatile한 메모리라서 전원 차단시에도 데이터가 유지되어. 하지만 Dram에비해 속도가 느려서 Nowadays는 거의 쓰이지 않음. 
     
     # 버블 메모리의 미래 
     버블 메모리는 이미 구식이 된 기술이기 때문에, 미래에는 더 이상 쓰이지 않을 거임. 하지만 버블 메모리의 기술이 다른 메모리 기술 개발의 기반이 되어서 중요한테, 여전히 연구되고 있고, 새로운 기술로 발전하고 있지.
     
     요즘은 flash memory 같은게 떠서 bubble memory를 쓸일은 없지만, 그래도 Bubble memory는 메모리 기술의 역사에 큰 걸림돌을 만들어낸重要한 기술이니까, 잊으면 안돼.
