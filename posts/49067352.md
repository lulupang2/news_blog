# 스맛 마리오 64 라이브러리 나왔어!
슈пер 마리오 64를 다른 게임 엔진에서 마음대로 쓸 수 있어! 
이 프로젝트는 마리오의 움직임과 렌더링 코드를 깨달은 거라고 보면 되니까, 마리오를 다른 게임 엔진에 던져 넣을 때 최소한의 노력만 필요해.
이 프로젝트는 공유 라이브러리 파일을 만들어내고, 공식 SM64 ROM을 런타임에 불러와서 마리오의 텍스처와 애니메이션 데이터를 얻어야 해.
클라이언트 프로젝트에서는 라이브러리에 대한 헤더 파일만 포함시키고 라이브러리를 불러오기만 하면 되거든.
예시 프로젝트도 같이 딸려나와서, 라이브러리 사용법을 보는 건 별로 어려울 것 없어 보임.
Bindings와 plugins은 Rust, Odin, Unity, Blender, Godot, Game Maker 8, Unity MelonLoader, C# 등 다양한 언어와 플랫폼을 지원해 줘.
### 빌드 방법
- **Mac과 Linux**: 파이썬3이 설치되어 있어야 하고, SDL2와 GLEW 라이브러리가 있어야해. 
- **Windows**: MSYS2 MinGW 64를 설정하고,SDL2와 GLEW 라이브러리 설치 후 빌드하면 돼.
- **Emscripten (웹)**: emmake make CC=emcc 명령어로 빌드할 수 있고, standalone 라이브러리를 만들고 싶으면 emcc로 별도로 빌드하면 된댔어.
-make lib:共有 라이브러리 파일을 빌드해 줘.
-make test: 라이브러리와 테스트 프로그램을 빌드해 줘.
-make run: 빌드한 테스트 프로그램을 실행시켜 줘.
