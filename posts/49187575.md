## Muse Code 떴다!! 
   무제한 코드 자동화해 주는 Muse Code가 떴음. 
   이건 Muse Spark 1.2 기반으로 만들어졌고, 맥이나 리눅스에서 쓸 수 있게 해줌. 
   ### 코드 자동화 
   Muse Code는 여러 가지 소프트웨어 엔지니어링 작업을 자동화해 주는데, 
   예를 들어 프로젝트 계획 세우는 작업, 코드 작성, 결과 확인 등을自动화 해줌. 
   그리고 여러 개의 서브 에이전트를 활용해 어려운 문제를 빨리, 정확하게, 거의 무인으로 풀어내주는能力이 있음. 
   ### 백그라운드 에이전트 
   Muse Code는 메인 에이전트와 백그라운드 에이전트로 구성되어 있는데, 
   백그라운드 에이전트는 각 작업마다 새로 생성되는 게 아니라, 
  Persistent하게 계속 동작해서 정보 수집을 반복하는 걸 피할 수 있음. 
   이렇게 하면 레이턴시를 줄이고, 어려운 작업을 처리할 때도 중간에 끊기는 일이 없게 해줌. 
   ### 런타임 디자인 
   Muse Code는 모든 모델 호출, 툴 실행, 승인, 편집 내역을 기록해 둠. 
   이렇게 되면 런타임을 재현할 수 있고, 오류가 났을 때도 이전에 중단한 지점부터 다시 시작할 수 있게 해줌. 
   ### 기본 스킬 
   Muse Code는 기본적으로 여러 가지 스킬을 내장하고 있는데, 
   예를 들어 `/plan` 명령은 작업을 승인된 계획으로 바꿔주고, 
   `/grill` 명령은 계획을 스트레스 테스트해 주는 기능임. 
   ### 새로운 모델 
   Muse Spark 1.2는 Muse Spark 1.1의 업데이트된 버전으로, 
   코드 생성, 디버깅, 코드 이해, 엔드투엔드 개발 워크플로우 등 여러 가지 기능이 개선됨. 
   ## 사용해 보기 
   Muse Code를 사용해 보면, 
   예를 들어 비디오를 입력으로 받아서 vacation home marketing and booking page를 자동으로 만들어 주는 식으로 사용할 수 있음. 
   ## 평가 
   Muse Spark 1.2는 다양한벤치마크 테스트에서 우수한 성능을 보여줌. 
   특히 long-horizon coding task에서 매우 뛰어난 능력을 보여줌. 
   ## 결론 
   결론적으로, Muse Code와 Muse Spark 1.2는 자동화 코드 작성과 소프트웨어 엔지니어링 작업을 매우 효율적으로 처리할 수 있는 도구임.
