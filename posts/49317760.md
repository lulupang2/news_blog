# 리틀러너: 초등 교과서만으로 학습하는 인공지능 
 리틀러너는 브라우저에서 실행할 수 있는 5B 모델을 제공해. 새 탭에서 열면 실행돼. 
 이건 어떻게 만들었냐면,現代의 인공지능들은 다 같이 학습을 하니까 어떤 새로운 기능이 추가되었는지, 아니면 그냥 나타난 건지 확인하기 힘들어. 
 그래서 학습 자료 자체를 제한했다는 뜻이야. 미국 초등 교과서 필터링한 88B 토큰 корп스를 만들었고, 거기에 모델을 학습시켰어. 
 리틀러너는 초등교과서만으로 학습한 0.6B, 1.3B, 5B 모델을 제공해. 이 모델들은 대화가 가능하고, 지식 경계가 명확해. 
 그리고 각 모델은 매칭된 무제한 제어를 제공해. 이는 깨끗한 비교를 위해 필요한 거야. 
 
 # 실험 결과 
 리틀러너模型은 확실히 초등 교과서 안에서만 학습할 수 있었어. 
 스케일링, SFT+GRPO 학습, 콘텍스트 학습 등은 초등 교과서에서 가르친 내용을 증폭시키지만, 범위를 벗어난 성능은 의미 있게 향상시키지 못해. 
 즉, pre-training 필터가 능력의 한계를 정한다는 거야. 
 
 # 결론 
 리틀러너는 초등 교과서만으로 학습한 인공지능 모델이야. 
 우리는 이것을 사용해서, 인공지능이 초등 교과서 안에서만 학습할 수 있는지, 아니면 더 나아갈 수 있는지 연구할 수 있어. 
 리틀러너 모델은 인공지능 연구에 새로운 시야를 제공할 수 있을 거야. 
 
 # 연구 방향 
 리틀러너는 여러 방향으로 연구할 수 있어. 
 예를 들어, 강화 학습이 인공지능의 능력을 향상시킬 수 있는지, 지속 학습이 인공지능의 지식을 어떻게 확장하는지 등이야. 
 우리는 리틀러너를 사용해서, 인공지능의 능력을 더 높일 수 있는지研究할 수 있을 거야. 
 
 # 마치며 
 리틀러너는 인공지능 연구에 새로운 길을 열어줄 수 있어. 
 우리는 리틀러너를 사용해서, 더智能한 인공지능을 만들 수 있을 거야. 
 리틀러너, 일등공신이 되어라!
