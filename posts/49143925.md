# F* 언어는 quoi? 
F* 언어는 함수형 프로그래밍과 효과적인 프로그래밍을 모두 지원하는 언어임. 이 언어는 의존성 유형과 증명 자동화 기능을 결합해서 SMT 해결 및 전도법 기반의 상호작용 정리证明을 제공함. 
### F*의 특징
*   F*는 OCaml로 컴파일됨
*   F*의 일부는 KaRaMeL이라는 툴을 사용해서 F#, C或者 Wasm으로 추출할 수 있음
*   F*는 OCaml로 구현되었으며, F* 자체를 사용해서 부트스트랩됨 
*   F*는 GitHub에서 오픈소스로 개발되고 있음. 
*   F*는 Apache 2.0 라이선스를 사용함
### F*를 사용하는 방법
*   F*를 GitHub에서 다운로드할 수 있음
*   F*는 Windows, Linux, Mac OS X 모두에서 사용할 수 있음
*   F*는 OPAM, Docker, Nix를 사용해서 설치할 수 있음
*   F*는 소스 코드에서 직접 빌드할 수 있음 
### F*의 장점 
*   높은 수준의 보안이 가능함. 
*   코드의 정확성을 chứng명할 수 있음. 
*   다양한 플랫폼에서 사용할 수 있음 
### F*를 사용하는 프로젝트
*   Project Everest: 보안 커뮤니케이션 소프트웨어를 개발하는 프로젝트임 
*   HACL*: 암호학적 원시 함수를 제공하는 라이브러리임
*   EverCrypt: 여러 암호학적 라이브러리를 결합해서 만든 암호학적 제공자임
*   EverParse: 2진형식 파일을 파싱하는 파서 생성기임
