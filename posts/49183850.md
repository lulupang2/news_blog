### 개요
Qwen 이미지 3.0 프로가 출시됨. 이 모델은 이미지 생성에 진짜 쓸만함ㅋㅋㅋ. 
이미지 안에 이미지 넣는 레이아웃도 지원하고, 10px짜리 텍스트도 그린다니까 ㄹㅇ 신기하지 않냐고? 
또한 12개국어와 20개 이상의 폰트를 지원해서 웹사이트나 게임, 라이브 스트림도 진짜로生成할 수 있대.
### 주요 기능
* **Prefix Completion**: API 호출할 때 Prefix를Strict하게続게 할 수 있음. 
* **Partial Mode**: 일부 모드 활성화도 가능.
* **Cache Context Cache**: 요청들어올 때 Prefix 캐싱 해줌.
* **Structured Outputs**: JSON형식의 출력 지원.
* **Batches**: 요청들을 일괄 처리.
* **Web Search**: 웹 검색 지원.
* **Fine-tuning**:모델 학습도 가능.
### 가격 정보
