### 탈스케일 최신 트릭: 진브레이컨 킨들을 더 강력하게 해보자
   탈스케일アップ 이벤트에 온당가? [탈스케일 업 이벤트](https://tailscale.com/up/)로 이동해서 티켓을 가져와.
   블로그에 가서 탈스케일의 최신 소식을 확인해보자.
   2026년 6월 12일
   진브레이컨 킨들에 탈스케일을 설치하기 전에 너무 오래 기다리면 업데이트가 되어버리는데, 이 부분을 개선한 최신 탈스케일이 나왔음. 
   오픈소스 개발자들이 너의 진브레이컨 킨들을 더 강력하게 만들어주고 있어. 
   탈스케일 SSH 기본 활성화, 프록시 모드, TUN 모드가 가능해졌음. 
   ### 탈스ケ일의最新機能
   * 탈스케일 SSH 기본 활성화: USB 네트워킹 SSH 없이도 默认 사용자/암호로 접속 가능
   * 프록시 모드: KOReader와 같은 앱이 tailnet의 다른 노드에 접근할 수 있음
   * TUN 모드: 일부 킨들에서 탈스케일 네트워킹이 장치 수준에서 작동할 수 있음
  KOReader를 쓸 때 Calibre나 Wallabag 서버에 접근할 수 있게 해줌. 
   이 기능들을 설정하는 방법은 아래에 설명되어 있음. 
   ###설정 방법
   * 탈스케일을 실행하고 KOReader의 프록시 설정을 127.0.0.1:1055로 설정
   * KOReader가 100.x.y.z와 같은 탈스케일 IP 주소에 접근하려고 하면, 탈스케일의 데몬이 이 연결을 라우팅해줌
   이것은 탈스케일이 KOReader와 같은 앱이 tailnet의 다른 노드에 접근할 수 있도록 해줌.
   SOCKS5와 HTTP CONNECT 프로토콜을 지원해서, 여러 앱의 호환성을 높여줌. 
   탈스케일의 이 프록시 기능은 KOReader의 Tailscale 플러그인과도 호환됨. 
   이 플러그인을 사용하면 KOReader에서 탈스케일을 사용할 수 있고, Tailscale의 기능을 KOReader와 통합할 수 있음. 
   ### 탈스케일 KOReader 플러그인
   탈스케일 KOReader 플러그인은 KOReader에서 탈스케일을 사용할 수 있도록 해줌. 
   이 플러그인을 사용하면 KOReader에서 탈스케일의 프록시 기능을 사용할 수 있음. 
   탈스케일 KOReader 플러그인을 사용하면 KOReader에서 탈스케일의 프록시 기능을 사용할 수 있어, Calibre나 Wallabag 서버에 접근할 수 있음. 
   이 플러그인은 Kobo와 PocketBook 장치에서도 작동함. 
   설치 방법은 킨들을 진브레이크하는 것과 유사해서, 이미 진브레이크ประสบ을 가진 사람이라면 쉽게 설치할 수 있을 거임. 
   플러그인을 KOReader의 플러그인 디렉토리에 복사하고, KOReader의 메뉴에서 'Tailscale 설치/업데이트'를 선택하면 됨. 
   그리고 탈스케일 키를 디렉토리에 복사하고, KOReader의 메뉴에서 탈스케일을 활성화하면 됨. 
   이 플러그인은 SyncThing 플러그인과 함께 사용할 수 있어서, KOReader에서 탈스케일과 동기화를 모두 사용할 수 있음. 
   ###まとめ
  탈스케일의 최신 업데이트 내용을 바탕으로, 탈스케일을 진브레이컨 킨들에 설치해서 쓰는 방법을 설명함. 
  탈스케일의 프록시 기능과 KOReader 플러그인을 사용하면 KOReader에서 탈스케일의 기능을 사용할 수 있고, Calibre나 Wallabag 서버에 접근할 수 있음. 
  이 플러그인은 Kobo와 PocketBook 장치에서도 작동해서, 다양한 장치에서 탈스케일을 사용할 수 있음.
