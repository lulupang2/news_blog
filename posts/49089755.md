# 코드 전문가들의 안심 보장 서비스 'Codex Security' 나왔다 ㄹㅇ
_openai/codex-security_란 클라이언트와 타입스크립트 SDK로서 코드에서 보안 취약점을 찾고 검증하고 고치는 역할을 한다. 저장소 스캔, 변경 사항 검토, findings 추적, CI에서 보안 체크를 수행할 수 있단다. 문서는 [공식 사이트](https://github.com/openai/codex-security)에서 확인 가능하다.
##_quick start_
노드js 22 이상, 파이썬 3.10 이상, 그리고 Codex Security 접근 권한이 필요하다. 설치 명령어는 다음과 같음:
```bash
npm install @openai/codex-security
npx codex-security login
npx codex-security scan .
```
CI 설정할 때는 `OPENAI_API_KEY` 환경 변수 설정 필요합니다. 둘 다 사용 가능하다면, 인터랙티브 스캔할 때는 인증 방법을 선택할 수 있음. 선택하기 위해 명령어 다음과 같이 사용하면 됨:
```bash
npx codex-security scan . --auth chatgpt
npx codex-security scan . --auth api-key
```
##_TypeScript SDK_
다음과 같이 사용할 수 있다:
```typescript
import { CodexSecurity } from '@openai/codex-security';
const security = new CodexSecurity();
const result = await security.run('.');
console.log(result.reportPath);
await security.close();
```
더 자세한 설치 방법이나 셋팅은 [공식 문서](https://github.com/openai/codex-security)에서 확인하면 됨.
