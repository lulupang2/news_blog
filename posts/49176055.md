### 디브센터링 개빡チ는 점
웹뷰 센터링 하는 법을ในที่สุด 익혔다가 브라우저에 사이드바가 생기면서 또 문제가 생긴 거임ㅋㅋㅋㅋ 
예전에는 센터링 할 때마다 이런식으로 코드를 짰음:
```css
.thing { 
  position: absolute; 
  top: 50%; 
  left: 50%; 
  transform: translate(-50%, -50%); 
}
```
근데 요즘엔 그냥 간단하게 그래이드 사용해도 센터링이 가능함ㅋㅋㅋㅋ  
```css
body { 
  display: grid; 
  min-height: 100dvh; 
  place-items: center; 
}
```
이 코드를 사용해서 `.site` 디브를 센터링해 봤지만 브라우저에 사이드바를 키니까 또 왠지 모를 이유로 센터링이 안 되는 거임ㅋㅋㅋㅋ  
일단 자바스크립트로 브라우저 윈도우 크기와 웹뷰 크기를 구해서 차이를 계산해 봄:
```javascript
window.innerWidth // 웹뷰 크기
window.outerWidth // 브라우저 윈도우 크기
const browserChrome = window.outerWidth - window.innerWidth;
```
그리고 左側에 있는 사이드바의 절반 크기만큼 `.site` 디브를 이동시킴:
```css
const shift = -browserChrome / 2;
.site { 
  translate: var(--window-center-shift, 0px); 
}
```
근데.devtool을 켜니까 또 센터링이 안 돼서 개빡침ㅋㅋㅋㅋ  
이번엔 포인터 이벤트를 사용해서 웹뷰의 좌표를 구해 봄:
```javascript
const viewportLeft = event.screenX - event.clientX * scale;
const viewportRight = viewportLeft + innerWidth * scale;
const left = viewportLeft - window.screenX;
const right = window.screenX + outerWidth - viewportRight;
const shift = (right - left) / (2 * scale);
```
파이어폭스 브라우저는 이 값들을直接 노출해 줌ㅋㅋㅋㅋ 
근데 크롬 브라우저는 안 알려주니까 확장프로그램을 만들어서 직접 계산해 줌ㅋㅋㅋ  
이 확장프로그램을 사용하면 센터링이 안 되는 페이지도 강제로 센터링시킬 수 있음ㅋㅋㅋ
