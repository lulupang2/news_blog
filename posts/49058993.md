# 토큰 리셀러 시장은 어떻게 돌아가는 거야? 


      요즘 토큰 리셀러 시장에 대해서 많이 얘기하잖아? 그래서 내가 찾아봤어. 

 
      토큰 리셀러 시장은 4개의 레이어로 구성되어 있다고 함. 업스트림 계층, 미드스트림 계층, 다운스트림 계층, 그리고 최종 사용자 계층이 있어.

 
      업스트림 계층에서는 카드 상점과 계정 상점이 虚拟 신용카드를 판매하고,.bulk-registered 계정을 판매하는 곳이야.

 
      미드스트림 계층에서는 계정 풀을 관리하는 곳들이 있어. 계정 풀에서는 업스트림 계층에서 생성된 계정들을 수집하고, 인증 토큰과 속도 제한을 관리하고, 장애 발생 시 대체 계정을 제공해줘.

 
      다운스트림 계층에서는 계정 풀의 API를 사용해서 중국어 지원 서비스를 제공하고, 가격을 경쟁적으로 책정해서 최종 사용자에게 판매해줘. 

 
      최종 사용자 계층에는 개발자와 스타트업, mid-sized SaaS 회사들이 있어. 이들은 저렴한 가격에 모델을 사용하기 위해 토큰 리셀러 시장에 참여함.

 
      # 토큰 리셀러 시장의 소프트웨어는 어떻게 작동하나요? 

 
      토큰 리셀러 시장에서 사용되는 소프트웨어는 주로 두 가지 오픈소스 프로젝트인 one-api와 new-api를 사용해. 

 
      one-api와 new-api는 OpenAI 호환 게이트웨이 프로젝트야. 이들은 Relay/transfer station 에서 사용되는데, 사용자들에게 API 키를 제공하고, 사용량을 추적하며, 요금을 청구할 수 있어. 

 
      # 누구こんな 것을 사용하고 있을까? 

 
      토큰 리셀러 시장에서 가장 많이 사용되는 방법은 무료 시험판 남용, chargeback 공격, 선불 카드 사용, 모델 거르기, 지갑 거부 공격이야.

 
      # 어떻게 방어할 수 있을까? 

 
      토큰 리셀러 시장과 같은 시장에서는 항상 수수료를 높이고, 계정 생성을 어렵게 만들고, 자동화 신호를 감지하고, 비정상적인 행동을 감지해야 해.
