# Fuse: 신나게 함수형 프로그래밍
 fuse는 정적 타입, 순수 함수형 언어야. 고차 타입과 ad-hoc 다형성이 지원돼. GRIN 전체 프로그램 최적화기로 컴파일되고, LLVM으로 네이티브 코드가 생성됨.
 
 ### Fuse 특징
 - 정적 타입: 시스템 F 기반의 타입 시스템이고 고차 다형성이 지원됨. 代수적 데이터 타입, 제네릭, 트레이트 등으로 도메인을 모델링할 수 있어.
 - 순수 함수형: 함수가 모두 순수 함수야. 패턴 매칭, 고차 함수, do notation 등으로 코드를 작성할 수 있어.
 - 타입 추론: 고차 타입을 지원하는 양방향 타입 검사기야. 함수 타입 시그니처만 있어도됨. 나머지는 자동으로 추론해줌.
 - 깔끔한 문법: 러스트, 파이썬, 스칼라, 하스크렐 등에서 영감을 받아 함수형 프로그래밍에서 읽기 좋은 문법을 제공해 줌. 인덴트 기반 블록, 람다 식, ML 같은 문법이 코드를 깔끔하게 해줌.
 - GRIN 컴파일: GRIN을 통한 전체 프로그램 최적화와 LLVM을 통한 코드 생성으로 빠르고小한 네이티브 바이너리가 생성됨.
 
 ### Fuse 설치
 Fuse 툴체인을 리눅스(x86_64)나 맥OS(ARM64)에 설치할 수 있어.
 ```bash
curl -fsSL https://fuselang.github.io/fuse/fuseup | sh
```
