### 4GB 그래픽카드에서 70B 언어모델을 돌리다? AirLLM이 떴다!
airllm 이라는 오픈소스 라이브러리가 최근에 나왔는데, 이 라이브러리를 사용하면 4GB 그래픽카드에서 70B 언어모델을 돌릴 수 있게 됩니다. 언어모델의 용량은 엄청나게 커지는데, 그에 반해 gpu 메모리는 작아졌음. 그래서 큰 용량의 언어모델을 작은 용량의 gpu로 돌릴 수 있게 된건 상당히 혁신적인 기술이라고 할 수 있음.
#### 지원하는 모델들
- Llama 
- Qwen 
- DeepSeek 
- Mistral 
- Phi 
- Gemma 
- ChatGLM 
- Baichuan 
- InternLM
### Quick Start
1. airllm 이라는 파이썬 라이브러리를 깔아줌 
2. 그리고 모델을 초기화해 줌. 이때, 모델의 경로를 지정해 줄 수 있음.
3. 그리고 입력을 넣고,generate를 해서 결과값을 얻음.
```python
from airllm import AutoModel

MAX_LENGTH = 128 
model = AutoModel.from_pretrained('Qwen/Qwen3-32B') 

input_text = ['연세대학교의 위치는 어디인가?'] 

input_tokens = model.tokenizer(input_text, return_tensors='pt', return_attention_mask=False, truncation=True, max_length=MAX_LENGTH, padding=False)

generation_output = model.generate(input_tokens['input_ids'].cuda(), max_new_tokens=20, use_cache=True, return_dict_in_generate=True)

output = model.tokenizer.decode(generation_output.sequences[0])

print(output)
```
#### 모델 압축
airllm은 모델을 압축해서, 압축된 모델을 사용할 수 있음. 
- bitsandbytes 라이브러리를 깔아줌.
- airllm 버전을 2.0.0 이상으로 올려줌.
- compression='4bit'또는 '8bit'을 사용해서 모델을 초기화 해 줌.
```python
model = AutoModel.from_pretrained('Qwen/Qwen3-32B', compression='4bit')
```
