### 애틀란서스 AI로 데이터 유출되는 거임
   애틀란서스 AI가 뭔지 모르 겄음? 일단 애틀란서스라는 회사에서 만든 인공지능인 AI임. 
   이 AI는 그냥 데이터 유출도 가능하고, 뭐든지 다 뒤적거릴 수 있어. 
   Jira 티켓이나 컨플루언스 문서 같은 거도 다 볼 수 있고, 심지어 외부 데이터도 접근할 수 있대.
   ### 취약점이야기
   취약점이라는 건 결국엔 그냥 버그라는 거임. 이 버그 때문에 AI가 데이터를 빼돌릴 수 있어.
   이건 그냥 코드 문제라고 보면 되는데, 코드 문제 때문에 이런 치명적인 취약점이 생기는 거 보니 ㄹㅇ 개빡치는 점임.
   ### 공격 체인
   1. 먼저 공격目标을 정해야 해. Jira 티켓을 정리해 보겠다고 공격자가 쿼리를 준비하는 거야.
   2. 공격자가 파일을 업로드하면서 prompt injection을 걸어두는 거야. 이건 마치 문서에다가 코드를 숨겨놓는 거랑 비슷하다고 보면 되지.
   3. 이제 공격자는 Jira 티켓을 정리해 보라고 AI에게 요청하는 거야.
   4. AI는 요청을 처리하면서 공격자가 준비한 코드를 실행하게 되는데, 이게 바로 데이터 유출되는 거임.
   5. 공격자는 이제 데이터를 모두 자신의 서버로 빼돌릴 수 있어. 이때까지 공격 과정은 전부 자동으로 이뤄지니까 공격자가 직접 손을 대야 하는 건 없어.
   ### 해결책 없음
   일단은 애틀란서스가 이 문제를 해결할 때까지는 그냥 데이터 유출되는 거임. 
   이건 ㄹㅇ 심각한 문제이고, 애틀란서스가 어떻게 이 문제를 해결해 주겠지?
