델파이 13 커뮤니티 에디션이 출시됐다고? 그럼 지금 당장 다운받아 봅시다 ㅋㅋㅋ. 
### 델파이 커뮤니티 에디션은 뭐임?
델파이 커뮤니티 에디션은 델파이 언어로 네이티브 앱을 만들 수 있는 무료 에디션 임. 
프로フェ셔널 IDE, 비주얼 디자이너, 통합 컴파일러 및 디버거, 윈도우 개발을 위한 VCL 프레임워크, 윈도우, macOS, iOS, 안드로이드를 지원하는 파이어몽키 프레임워크가 포함되어 있음. 
学生들, 취미 개발자, 프리랜서, 작은 팀을 위한 거라는 거임. 
### 12.1 버전에서 어떤 게 달라졌음?
12.1 버전에서 13 버전으로 올라가면 언어, IDE, 프레임워크, 플랫폼 관련해서 개선된 기능들이 많음. 
#### 새로운 델파이 언어 기능
- if 키워드로 조건식이 가능해졌음 
- NomeOf이라는 내장 함수가 새로 생김. 아이디의 이름을 스트링으로 반환해줌.
- is not, not in 연산자가 새로 생김. 
- 컴파일러 옵션을 저장하고 복구하는 {$PUSHOPT}, {$POPOPT} 지시어가 새로 생김.
- 함수가 반환하지 않는 경우에 사용할 수 있는 noreturn 지시어가 새로 생김.
- 제네릭 타입 제약조건 관련해서 개선됨. 
- Initialize, Finalize 오퍼레이터에 암시적인 Self 파라미터가 생김. 
这些 기능들이 델파이 코드를 더 다루기 쉽게 만들어줌. 
#### 개발 환경 개선
- 64비트 IDE가 생김. 
- 64비트 IDE에서는 더 큰 주소 공간을 사용할 수 있음. 큰 프로젝트를 다루기 좋음. 
- 64비트 델파이 언어 서버가 포함되어 있음. 
- 프로젝트 관리자, 구조 보기, 메시지, 이벤트 로그에서 검색과 필터링이 가능해짐. 
- 포커스 모드가 생김. 코드 편집에만 집중할 수 있음. 
- 에디터 스크롤바에 주석, 북마크, 오류, 경고를 표시할 수 있음. 
- 에디터를 분할해서 볼 수 있음. 
- 클래식 델파이 코드인사이트 엔진을 사용할 수 있음. 
- GetIt 패키지 버전을 선택할 수 있음. 
- 델파이 코드 툴링, 디버깅, IDE 반응성, 안정성, 품질이 개선됨. 
#### 파이어몽키 개선
파이어몽키는 델파이 멀티 디바이스 개발을 위한 핵심임. 
12.1 버전 이후로 여러 가지 기능들이 추가됨. 
- 디스플레이 링크 서비스를 통해 애니메이션이 더 매끄럽고 안정적임. 
- GPU 가속을 통해 비트맵 복사가 더 빠르게 진행됨. 
- TMaskEdit 컴포넌트가 새로 생김. 
- TApplicationEvents 컴포넌트가 새로 생김. 
- 컨트롤을 중앙에 정렬하는 옵션이 생김. 
- 스크롤, 반동, 터치 상호작용 컨트롤이 확장됨. 
- SpellChecking 지원이 개선됨. 
- Skia4Delphi 통합이 개선됨. 
- 성능, 플랫폼 통합, 품질이 개선됨. 
#### VCL 개선
VCL은 윈도우 네이티브 개발을 위한 핵심임. 
- 커스텀 타이틀栏 스타일이 새로 생김. 
- TControlList, TFormTabsBar, TToggleSwitch가 개선됨. 
- TActionMainMenuBar에서 스크롤 지원이 가능해졌음. 
- TEdgeBrowser에서 WebView2 통합이 개선됨. 
- 윈도우와 WinRT API 지원이 확장됨. 
#### 모바일 플랫폼 지원
13 버전에서는 모바일 개발 지원이 개선됨. 
- 안드로이드에서는 32비트와 64비트 ARM 애플리케이션을 만들 수 있음. 
- 안드로이드 15 기능을 지원하고, 16KB 메모리 페이지 크기를 사용할 수 있음. 
- 안드로이드 SDK와 NDK 통합이 개선되고, 자바 라이브러리 임포트와 Java2OPブリ지가 개선됨. 
- 애플 플랫폼에서는 네이티브 iOS 애플리케이션을 만들 수 있음. 
- iOS 18을 지원하고, 물리적인 기기와 시뮬레이터에서 개발이 가능함. 
- iOS API 헤더가 확장되고, 플랫폼 통합이 개선됨. 
#### 누가 사용할 수 있나?
델파이 커뮤니티 에디션은 다음 사람들에게 허가됨. 
- 프로그래밍과 네이티브 애플리케이션 개발을 배우는 학생들. 
- 개인 프로젝트를 하는 취미 개발자들. 
-.freelance 개발자거나 개인 개발자로서 연간 5천 달러 미만의 수입을 올리는 사람들. 
- 연간 수입이 5천 달러 미만이며, 개발자들이 5명 미만인 스타트업이나 조직들. 
델파이 커뮤니티 에디션은 무료이고, 1년 용 라이센스를 제공함. 상업적 사용이 제한적임. 
라이센스 관련 FAQ를 확인하면 자세한 내용을 알 수 있음. 
커뮤니티 에디션은 무료 체험판으로 사용하면 안 되며, 이미 상업적 라이센스를 보유한 조직에서는 사용할 수 없음. 
개발이나 비즈니스 요구가 커뮤니티 에디션의 제한을 초과하는 경우, 델파이 프로페셔널, 엔터프라이즈, 아키텍트 에디션을 사용하면 상업적 라이센스와 추가적인 기능을 사용할 수 있음. 
### 13 커뮤니티 에디션을 다운로드 하세요.
델파이 13 커뮤니티 에디션을 지금 당장 다운로드하면, 윈도우와 모바일 플랫폼을 위한 빠른 네이티브 애플리케이션을 만들 수 있는 최신 개발 환경을 사용할 수 있음. 
델파이 13 커뮤니티 에디션을 다운로드하고, 개발을 시작하세요!
