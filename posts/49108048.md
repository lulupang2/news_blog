# 라즈베리 파이 gpiozero 프로젝트
라즈베리 파이에서 gpio 디바이스 제어할 때 편하게 해 주는 라이브러리인 gpiozero가 있음. 
이 라이브러리는 프로세서에서 gpio 디바이스를直接 제어하는 대신, 버튼이나 센서, 모터 등 디바이스 자체의 동작에 중점을 두는 방식임. 
예를 들어 gpiozero로 버튼을 누르면 LED가 켜지는 코드를 작성할 수 있음.
```python
from gpiozero import Button, LED

button = Button(17)
led = LED(23)

while True:
    if button.is_pressed:
        led.on()
    else:
        led.off()
```
이 코드는 버튼을 누르면 LED가 켜지고, 버튼을 뗌으면 LED가 꺼지게 함. 
이외에도 이벤트 기반(event-based) 프로그래밍이나 선언적(declarative) 프로그래밍 방식도 지원함. 
이러한 프로그래밍 방식은 코드를 더 간단하고 읽기 쉽게 만들어줌. 
gpiozero는 다양한 디바이스를 지원하고, 디바이스 간의 연결을 쉽게 설정할 수 있도록 해줌. 
예를 들어, 버튼을 누르면 모터가 회전하는 코드를 작성할 수 있음.
```python
from gpiozero import Button, Motor

button = Button(17)
motor = Motor(23, 24)

button.when_pressed = motor.forward
button.when_released = motor.backward
```
이 코드는 버튼을 누르면 모터가 앞으로 회전하고, 버튼을 뗌으면 모터가 뒤로 회전하게 함. 
gpiozero는 디바이스 간의 연결을 설정할 때, 값의 흐름을 쉽게 제어할 수 있도록 해줌. 
예를 들어, 버튼을 누르면 LED의 밝기를 조절하는 코드를 작성할 수 있음.
```python
from gpiozero import Button, PWMLED

button = Button(17)
led = PWMLED(23)

button.when_pressed = led.on
button.when_released = led.off
```
이 코드는 버튼을 누르면 LED가 켜지고, 버튼을 뗌으면 LED가 꺼지게 함. 
led의 밝기는 pwm(pulse width modulation) 방식으로 제어할 수 있음. 
이러한 기능은 라즈베리 파이에서 gpio 디바이스를 쉽고 편하게 제어할 수 있도록 해줌. 
이 이제 웹에서 드래그앤드롭으로 편하게 gpio 제어할 수 있게 된 븅신같은 프로젝트가 나왔 븅신아!!
