# 포스트그레스(Postgres) DB 분석 속도 300배 빠르게 만드는법
[링크](https://malisper.me/2023/02/20/rebuilding-postgres-for-300x-faster-analytics-batching-operator-fusion-and-simd/)\n포스트그레스 db 분석 속도를 300배 快하게 만드는 법은 batchizing, operator fusion, simd 임
배치 처리, 연산자 융합,simd 는 포스트그레스 db 분석 속도를 빠르게 하기 위한 방법중 하나 임
일반적으로 포스트그레스 db 에서 쿼리 분석시 볼로카노 모델을 사용하는데 이 모델은 단순하지만 오버헤드가 많이 발생함
そこで 배치 처리(batching)과 연산자 융합(operator fusion), simd를 통해 속도를提高할 수 있음
배치 처리를 통해 db 에서 데이터를 읽어올때 1건씩 읽어오는 것 보다는 한번에 여러건을 읽어오는 것이 속도 향상에 도움됨
연산자 융합은 연산을 하나의 노드로 묶어서 처리하는 것으로 중간 결과를暫時저장하지 않고 바로 처리하는 방식임
simd는 cpu 명령어를병렬처리하는것으로 여러개의 데이터를 동시에 처리할 수 있어 속도 향상에 도움이됨
이러한 방법을 사용하면 포스트그레스 db 분석 속도를 300배 빠르게 만들 수 있음
