   # N64 게임 만들기
   N64 게임 만들기 도전기 ㅋㅋㅋ. [도미닉 司](https://phoboslab.org/)가 직접 써본 방법을 공유함. 
   2년 전, JavaScript 게임 엔진을 C로 바꿨음. 그 이유는 N64 게임을 만들기 위해서였음! ㅋㅋㅋ. 
   Xibalba 64라는 게임을 만들었는데, 울펜스타인 3D 같은 FPS 게임임. 
   Modretro라는 회사에서 M64 카트리지를 제작해서 출시할 예정임. 이 게임은 2002년 토니 호크 프로 스케이터 3 이후로出版된 새로운 N64 게임중 하나임. 

   ## 게임 엔진
   Impact라는 게임 엔진을 만들었는데, 2D 액션 게임을 위한거임. 타일 시트,背景 맵, 스프라이트, 충돌 감지 등 기본적인 기능들만 있음. 
   이걸 C로 바꿨는데, high_impact라는 이름으로 바꿨음._platform backend_라는 개념을 도입했는데, 이건 게임을 실행하는 플랫폼을 뜻함. 
   high_impact에는 두 개의 플랫폼 백엔드가 딸려옴. SDL2와 Sokol임. 게임을 컴파일할 때 어느 플랫폼 백엔드를 사용할지 선택할 수 있음. 

   ## N64 하드웨어
   N64는 MIPS CPUと 두 개의 코프로세서로 구성되어 있음. Reality Display Processor (RDP)와 Reality Signal Processor (RSP) 임. 
   RDP는 그래픽 처리를 담당하고, RSP는 벡터 연산을 담당함. 
   이 두 개의 코프로세서는 reality coprocessor (RCP)로呼ば됨. 
   N64 하드웨어는 좀 특별한 편임. 프로그램을 직접 작성하기는 어렵고, Nintendo의 공식 라이브러리인 libultra를 사용해야 했음. 
  하지만, 최근에 N64 홈브류 시장이 발전하면서 libdragon이라는 라이브러리가 나왔음. 
   libdragon은 SDL과 비슷한 용도지만, N64용임. 

   ## 개발 환경
   libdragon을 사용해서 high_impact의 새로운 플랫폼 백엔드를 만들었음. 
   개발 환경은 довольно 좋은 편임. 문서화가 잘되어 있고,예제 코드도 많음. 
   하지만, 안정 버전이 구버전이라서, 미리보기 브랜치를 사용하는게 좋음. 
   에뮬레이터도 필요하고, Ares라는 에뮬레이터를 사용했음. 
   이 에뮬레이터는 N64 하드웨어를 khá 정확하게 구현하고 있음. 
   하지만, 하드웨어의 메모리 대역폭은 아직 제대로 구현되지 않음. 

   ## 게임
   Xibalba 64라는 게임을 만들었고, 울펜스타인 3D와 비슷한 게임임. 
   하지만, 2D 게임 엔진을 사용했기 때문에, 3D를模擬하기 위해서 몇 가지 트릭을 사용했음. 
   vec3_t라는 구조체를 만들어서, 3D 좌표를 나타냄. 
   그 뒤, 게임을 확장하고, 최적화를 하느라 몇 개월이 걸렸음. 
   레벨 에디터도 만들었고, 그 안에서 직접 게임을 테스트할 수 있게 했음. 
   레벨 에디터는 HTML 파일 하나로 구성되어 있고, JSON 파일을 읽어서 레벨 데이터를 로딩함. 
   하지만, N64에서 JSON 파일을 로딩하는 것은 불가능하지는 않지만, 비효율적이라서,_levelCompiler를 만들었음. 
   이 컴파일러는 JSON 파일을 읽어서, N64에서 로딩 가능한 이진 파일로 변환해줌.
