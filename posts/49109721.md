# Prized, 비개발자도 내부 툴 개발 가능한 서비스 출시
Prized는 Y Combinator의 S26 배치를 받은 회사로, 비개발자 스태프들이 안전한 내부 툴을 만들 수 있게 해줌. 개념은 간단함. AI를 기반으로 해서, non-engineer 스태프들이 내부 툴을 개발할 수 있게 해주면 됨.
## 기존 문제点
기존에는 내부 툴 개발이 개발자들만 할 수 있는 일이라, 비개발자 스태프들은 개발자들이 툴을 개발해 주기를 기다리거나, 직접 개발을 하는데 çok 많은 시간과 노력이 걸렸음. 그런데 개발자가 개발한 툴을 사용하는 비개발자들은, 툴을 수정하거나, 변경해야 하는 경우 개발자에게 의존해야ONLY 해야 했음.
## Prized의 해결 방법
Prized는 이 문제를 해결하기 위해, AI 기반의 내부 툴 개발 플랫폼을 제공함. 비개발자 스태프들은 이 플랫폼을 사용해서, 쉽게 내부 툴을 개발할 수 있음. 또, 이 툴은 안전성을 고려해서 설계되었기 때문에, 비개발자들도 안심하고 사용할 수 있음.
## Prized의 주요 기능
*   비개발자 스태프들이 내부 툴을 개발할 수 있게 해주는 AI 기반 플랫폼
*   내부 데이터베이스와의integration 지원
*   안전성과 보안성을 고려해서 설계됨
*   비개발자들이 쉽게 사용할 수 있게 설계됨
## Prized 사용 예시
다음은 Prized를 사용해서 만든 예시임.
*   고객 정보를 조회하는 내부 툴: 고객 정보를 쉽게 조회할 수 있는 내부 툴을 개발할 수 있음.
*   재정 정보를 분석하는 내부 툴: 재정 정보를 분석하고, 비용을 줄이는 방법을探索할 수 있는 내부 툴을 개발할 수 있음.
*   재고 관리를 위한 내부 툴: 재고를 효과적으로 관리하고, 재주문을 자동으로 처리할 수 있는 내부 툴을 개발할 수 있음.

이처럼 Prized는 비개발자 스태프들에게도 내부 툴 개발의 기회를 제공함으로써, 조직의 생산성을 향상시키고, 비용을 절감하는 데 도움이 될 수 있음. ㅋㅋㅋ
