# 8비트 CPU에 언어 모델 올리기

bbc micro 같은 구식 컴퓨터에 ai 언어 모델을 올려봄.
8비트 cpu에 언어 모델을 올리려면 여러 가지 문제가 있음.
첫째, 메모리가 너무 적음. 
둘째, cpu가 너무 느림.
셋째, 언어 모델이 너무 커서 메모리에 올리기 어려움.

그래서 언어 모델을 작게 만들어야하는데,
그렇게 하면 성능이 너무 떨어짐.
그래서 좋은 성능을 내는 작은 언어 모델을 찾아야겠음.

그렇게 찾은게 mamba 언어 모델임.
이 모델은 autoregressive 언어 모델임.
한 단어씩 만들어감.
예를 들어 'hello wor' 이면 'l' 단어를 만들어냄.

이 모델은 재귀적인 구조임.
이전 토큰에서 다음 토큰을 예측하는 구조임.
근데 8비트 cpu에서는 재귀가 어려움.
왜냐하면 메모리가 적어서 이전 토큰을 모두 저장하기 어려우니까임.

그래서 bitnet이라는 모델을 사용함.
bitnet은 행렬 곱셈을 빠르게 할 수 있는 모델임.
행렬 곱셈은 cpu에서 많이 쓰임.
근데 8비트 cpu에서는 행렬 곱셈이 어려움.
왜냐하면 곱셈 연산이 없니까임.

bitnet은 행렬을 3진수로 바꿔서 곱셈을 빠르게 할 수 있게 해줌.
3진수는 -1, 0, 1 세 가지밖에 없기 때문에 빠르게 할 수 있음.
근데 이렇게 하면 모델의 크기가 줄어들임.
그래서 모델의 크기를 줄여야하는데,
그렇게 하면 성능이 떨어지지 않을까?

그래서 여러 가지 실험을 해봄.
bitnet 모델과 일반적인 모델을 비교해봄.
-bitnet 모델이 일반적인 모델보다 성능이 좋았음.

그래서 8비트 cpu에 bitnet 언어 모델을 올리게 되었음.
bbc micro에서 돌려봤음.
성능이 많이 떨어졌지만, 동작은 되었음.

8비트 cpu에 언어 모델을 올리는 것은 아주 어려운 일임.
하지만 bitnet 모델을 사용하면 가능함.
bitnet 모델은 行列乘셈을 빠르게 할 수 있게 해줌.
8비트 cpu에서는 行列乘셈이 아주 어려운 일임.
하지만 bitnet 모델을 사용하면 성능이 좋음.
