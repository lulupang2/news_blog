# 소개
애플 비전 프로에서 안드로이드 ARM64 VR APK를 실행하기 위해서는 klepton 이라는 도구를 사용해야 함. klepton 은 안드로이드 .so 라이브러리를 애플 .dylib và .framework 라이브러리로 번역해서 klepton 런타임에 연결해給다.

# 특징
klepton 은 현재 자바 기반 애플리케이션에만 초점을 둠. 그래픽스 관련해서는 GLES 3.2 를 ANGLE GLES 3.0 으로 변환하고, Vulkan 은 MoltenVK 로 변환한다는 거임. 

## klepton-ld
klepton-ld 는 안드로이드 .so 라이브러리를 애플 .dylib 과 .framework 라이브러리로 번역해주는 도구야. 이 도구는 안드로이드 어플리케이션의 그래픽스 관련 라이브러리를 애플에서 사용할 수 있는 형식으로 변환해주는 역할을함.

# 빌드 및 실행
klepton を 사용해서 애플 비전 프로에서 안드로이드 VR APK를 실행하는 방법은 다음과 같음.
1. brew install pkg-config sdl3 apktool を 사용해서 필요한 도구를 설치한다.
2. apktool d -f -o beatsaber beatsaber.apk 를 사용해서 APK 파일을 추출한다.
3. make check 를 사용해서 전체 빌드를 테스트한다.
4.(build_run_viewer.sh, build_run_vpro.sh, build_run_slink.sh)를 사용해서 빌드 및 실행을 테스트한다.

## 상태
현재 비트세이버(Beatsaber)가 macOS와 visionOS에서 작동하지만 그래픽스 관련해서 약간의 문제점이 있다고 함. 스팀 VR링크(Steam VR Link)는 아직 작업중임.
