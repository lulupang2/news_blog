# 소개 
무료 오픈소스 프롬프트 엔지니어링 툴을紹介함. 이 툴은 로컬에서 돌아가는 거임. 즉, 사용자 데이터를 서버에 저장하지 않아 걱정 없다는 거임 ㅋㅋㅋ. 
## 주요 특징
* RTF 프레임워크를 사용해서 프롬프트를 생성하는 건데, 쉽고 유연한 구조임. 
* 다국어 지원하는 거 같음. 지원 언어 목록은 아직 찾지 못했지만 ㅋ 
* 주요 기능으로는 프롬프트 생성, 프롬프트 예시 보기, API 키 설정 등이 있음. 
* 로컬에서 돌아가기 때문에 서버 비용 없음.  
## 사용 방법 
1. 사용자 목적을 선택한다. (예: 블로그 포스팅, 이메일, 스토리 등) 
2. 프롬프트를 작성한다. (예: 제목, 콘텐츠, 키워드 등) 
3. 생성된 프롬프트를 사용한다. (예: AI 모델에 입력하여 결과를 얻음) 
## 장점 
* 무료로 사용 가능함. 
* 로컬에서 돌아가기 때문에 데이터 보안 걱정 없음. 
* 다양한 모델을 지원함. (예: ChatGPT, Gemini, Claude 등) 
## 결론 
요약하자면, 이 툴은 무료로 사용할 수 있고, 로컬에서 돌아가기 때문에 데이터 보안 걱정 없고, 다양한 모델을 지원하는 만능 프롬프트 생성기임. ㅋㅋㅋㅋ
