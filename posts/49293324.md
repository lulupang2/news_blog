### 블루스카이 프로토콜 서비스登場!
블루스카이 프로토콜 서비스가正式 출시되었고, 이것은 개발자들이 블루스카이의 인프라스트럭처를 이용할 수 있게 하는 새로운 홈페이지야. 이제 개발자들은 블루스카이의 도큐먼트를 쉽게 이용할 수 있고, 제트스트림과 Bluesky API 등을 쉽게 사용할 수 있게 되었어.

제트스트림)v2가 출시되어 네트워크 재생 기능을 제공하고, 개발자들이 블루스카이의 인프라스트럭처를 이용할 수 있게 해줘. 네트워크 재생 기능이란, 개발자들이 블루스카이의 네트워크에 저장된 데이터를 쉽게 조회할 수 있는 기능이야. 예를 들어, 개발자가 블루스카이의โพ스트를 조회하고 싶으면, 네트워크 재생 기능을 이용해서 해당 데이터를 조회할 수 있지.
#### 새로운 제트스트림 SDK
새로운 제트스트림 SDK가 출시되어, 개발자들이 제트스트림을 쉽게 사용할 수 있게 해줘. 제트스트림 SDK는 Typescript와 Go 언어를 지원하고, 개발자들이 제트스트림을 쉽게 사용할 수 있는 인터페이스를 제공해줘.

#### 업데이트된 HTTP 레퍼런스
HTTP 레퍼런스가 업데이트되어, 이제 개발자들이 블루스카이의 API를 쉽게 사용할 수 있게 해줘. HTTP 레퍼런스는 블루스카이의 API를 쉽게 사용할 수 있는 인터페이스를 제공하고, 개발자들이 블루스카이의 API를 쉽게 사용할 수 있게 해줘.
