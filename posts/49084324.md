# Obsidian은 개인 지식 관리 TOOL이라고 하지만... 
 Obsidian이라는 TOOL이 나오고 6년이 지났는데, PUBLIC에 보여지는 지식이나 이해도가 증가했는지 궁금해지는 건 사실임. 하지만 이거랑 TOOL의 관계는 어떤 건지 헷갈리네. 
 Emacs나 vim 같은 TOOL은 정말 오래됐는데, 이 TOOL은 PUBLIC에 보여지는 지식이나 이해도에 기여를 했다고 말할 수 있을까? 
 TOOL이 중요한 기여를 하는 건 아니지. TOOL은 사람들이 중요한 기여를 할 수 있도록 도와주는 것뿐임. 
 Brennan은 Obsidian에 대해선这么 말함. 'Obsidian은 LOCAL한 plain text 파일을 Markdown으로 작성하고, 데이터 프라이버시, 포터블, 미래 지향적인 TOOL이야.' 
 하지만Obsidian 홈페이지에 가보면, 'plain text 파일에 중요성을 두고, DROPBOX나 GIT으로 백업하거나, 디스크를 암호화하니까 TOOL 사용이 편리해' 이러는 건 사실임. '데이터 프라이버시', '포터블', '미래 지향적인 TOOL'이란 이야기는 찾아볼 수 없네. 
 Brennan은 Obsidian에 대해 잘못된 정보나 의견을 가지고 있는 거 같아. TOOL은 TOOL일 뿐이고, TOOL을 사용하는 사람이 중요한 기여를 하는 건지에 집중할 필요가 있어. 
 Obsidian은 TOOL이고, TOOL을 개발한 사람들이 말하는 것처럼 사람들이 TOOL을 사용해서 각자 자신의 시스템을 만드는 거지. TOOL 자체가 중요한 기여를 하는 건 아니고, TOOL을 사용하는 사람이 중요한 기여를 하는 거임.
