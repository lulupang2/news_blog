 ### 시스템드 린져 기능
시스템드의 린져 기능은 사용자가 로그아웃 할 때 프로세스를 유지할 수 있도록 해 줍니다. 
예를 들어, `screen` 또는 `tmux`와 같은 터미널 멀티플렉서를 사용하거나, `nohup`으로 프로세스를 실행하는 경우에 유용합니다.

#### 린져 기능 사용법
린져 기능을 사용하려면 `loginctl` 명령을 사용합니다. 
사용자는 자신의 계정에서 린져 기능을 활성화 또는 비활성화할 수 있습니다.
```bash
loginctl enable-linger
loginctl disable-linger
```
관리자 권한으로 실행하는 경우에는 다른 사용자의 계정에서도 린져 기능을 활성화 또는 비활성화할 수 있습니다.
```bash
loginctl enable-linger $ACCOUNT
loginctl disable-linger $ACCOUNT
```
#### 린져 기능의 장점
린져 기능을 사용하면 로그아웃 후에도 프로세스를 유지할 수 있으므로, 작업을 중단하지 않고 계속할 수 있습니다.
또한, 시스템을 재시작할 때에도 프로세스를 유지할 수 있으므로, 작업의 연속성을 유지할 수 있습니다.
