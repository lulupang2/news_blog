### 2D 코드의 세계에 오신 것을 환영하십니다!

코드를 작성할 때마다 우리들은 1D 코드를 작성합니다. 하지만, 생각해 보면 1D 코드는 정말 그렇게 좋은選択인지疑問이 생기는데요. 왜냐하면, 우리는 항상 왼쪽에서右쪽으로 코드를 작성한다는 점인데요. 하지만, 왜 2D 공간에서 코드를 작성하지 못할까요? 

예를 들어, 3-arity 함수는 1D 코드에서 작성하기 어렵습니다. 우리는 3-arity 함수를 작성할 때 여러번의 binary 함수를 composting 해야하는데요. 2D 코드에서는 이를 쉽게 작성할 수 있습니다.

#### 3-arity 함수의 예시

```python
def andFlip(args):
    if args[0] and args[1]:
        args[2] = not args[2]
    return args[2]
```

위 함수는 2개의 입력과 1개의 출력을 가지고 있는 함수입니다. 하지만, 1D 코드에서는 이를 작성하기 어렵です.

#### 2D 코드의 장점

2D 코드를 사용하면 여러개의 함수를 쉽게 작성할 수 있습니다. 또한, 코드의 가독성이 좋아집니다.

### 결론

2D 코드의 세계는 1D 코드의 세계와는 다릅니다. 우리는 2D 코드를 사용하여 더 복잡하고 difficile한 문제를 해결할 수 있습니다. 2D 코드의 세계로 오신 것을 환영합니다!
