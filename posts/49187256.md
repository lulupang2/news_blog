> **🔗 원문 보러가기:** [Zed DeltaDB](https://zed.dev/deltadb)

DeltaDB 는 코드를 수정하고 대화 내용을 모두 기록해주는 버전 관리 시스템 임.
    이건 개발 중인 소프트웨어를 위해 만들어진 건데, 커밋 사이의 모든 작업을 기록해서 대화를 통해 변경된 내용을 확인할 수 있음.
    DeltaDB 에 关於 더 알아보려고 하면 Github 아이디랑 메일주소를 입력해서 알파 테스트 에 참여할 수 있음.
    이걸 통해 언제든지 코드를 수정할 수 있고, 이전 버전으로 돌아가거나 특정 момент의 코드를 확인할 수도 있음.
    코드 하나하나에 대한 대화를 확인할 수 있고, 대화 내용에서 코드로 바로跳轉할 수도 있음.
    브랜치도 원하는 순간에 만들 수 있어서 코드를 협업할 때 굉장히 유용할 거임.
    DeltaDB 는 코드를 수정할 때 Conversation 을 남길 수 있해서 협업이 훨씬 용이해짐.
    이 기능은 개발자들이 코드를 수정하면서 발생하는 대화를 모두 기록해서 협업에 도움이 되게 해준다는 거야.
