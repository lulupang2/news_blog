### 니ックス 언어의 게으름
니ックス 언어는 정말로 게으르다. 특히 게으른 언어를 사용해 보지 않은 사람에게는 정말로 놀랄 만한 점이 있다. 이 게으름이 니ク스프그스(Nixpkgs)의 가능성을 만들고, 그 복잡성을 만들어 냈다. 게으름을 관찰하기 위한 가장 간단한 방법은 평가되는 속성이 접근되는 속성만이라는 것을 이해하는 것이다.

### 끝없는 마리오 Thế Giới
니ックス 언어의 게으름으로 인해 끝없는 마리오 게임 속의 Thế Giới를 구현할 수 있다. 각 노드는 트리의 setFrame이고, 각 자식은 버튼을 누르는 동작이다. 게임 상태는 재귀적이다.

```bash
nix build '.#level1.rightb.rightb.rightab.rightb'
file -L result
```
이 결과물은 PNG 이미지다. `.rightb`는 `right + B`로, 마리오 게임에서는 '우측으로 달리기'를 의미한다.

이런 방법으로 마리오 게임의 각 프레임을尼克斯 언어의 derivation으로 만들 수 있다. 그리고 `.play`를追加하면, 해당 경로의 모든 프레임을 하나의 동영상으로 만들 수 있다.

```bash
nix build '.#level1.rightb.rightb.rightab.play'
ls -l result/frames | head -4
```
이러한 derivation들은 니ックス 스토어에 저장되며, 각 프레임은 이전 프레임의 상태를 입력으로 받는다. 따라서 이전 프레임의 에뮬레이션을 다시 수행할 필요가 없다.

### 니克斯와 게임 입력
니ックス의 게으름과 게임 입력을 결합하면, 게임의 상태를 재귀적으로 표현할 수 있다. 각 게임 상태는 이전 상태와 버튼 입력으로부터 생성된다. 이런 방법으로 마리오 게임의 각 프레임을尼克斯 언어의 derivation으로 만들 수 있다.

```bash
nix eval --raw '.#game.start.wait4.start.drvPath'
```
이 결과물은 마리오 게임의 각 프레임을 니ックス 스토어의 derivation으로 만들어 낸다.

### 니克斯의 한계
니ックス 언어에는 한계가 있다. 최대 2,400개의 버튼 입력을 넘길 수 없다. 그러나 이 한계는 구조적 제한이 아니다.=max-call-depth 옵션을 늘려서 20,000개의 버튼 입력을 넘길 수 있다.

```bash
nix eval --raw --option max-call-depth 10000000 
   '.#game.$( python3 -c 'print(".".join(["right"]*20000))') .drvPath'
```
이 결과물은 마리오 게임의 각 프레임을 니ックス 스토어의 derivation으로 만들어 낸다.

### 결론
니ックス 언어의 게으름과 게임 입력을 결합하면, 게임의 상태를 재귀적으로 표현할 수 있다. 이런 방법으로 마리오 게임의 각 프레임을尼克斯 언어의 derivation으로 만들 수 있다. 니克斯 언어의 게으름은 단점으로 보일 수 있지만, 실제로는 매우 강력한 도구가 될 수 있다. 😄
