### 리レー 보호하기: 개빡치는 점

리レー가 뭔지 모르면 이하 내용을看고오셈 ㅋ. 리レー는 두 기기가 직접 연결할 수 없을 때数据를 전달해 주는 역할을 함. 그리고 만약에 리レー가 아무나 받을 수 있으면, 누구든지 리レー의 URL을 알아내면 트래픽을 전달할 수 있게 되는데, 이렇게 되면 악의적인 사용자들이 리レー 서버를 악용할 수 있지.
이런 문제를 해결하기 위해서, 이제부터는 Iroh Services의 관리되는 리レー服务器가 기본적으로 인증 토큰을 발급 받아서 쓸 수 있게 된 거임 ㅋ.

### 인증 토큰이란?

인증 토큰은 사용자의 프로젝트 API 키로 발급되는 거지. 이 토큰은 다음과 같은 정보를 담고 있단다:
*   발급한 사람: 사용자의 프로젝트 API 키
*   대상: 연결하는 Endpoint의 공개 키
*   권한: 리レー 사용 권한
*   만료 시간: 토큰이 사용できなくな는 시간

이러한 정보들로組成된 토큰을 사용해서 리レー 서버와 연결할 수 있게 되는데, 이제부터는 인증되지 않은 리レー 연결은 거부되는 거지.

### 사용법

사용법은 간단함. 기존에 사용하던 iroh_services preset을 사용하면,自動으로 토큰을 발급 받아서 연결할 수 있게 되는데, 이_preset은 사용자의 API 시크릿 키를 사용해서 토큰을 발급 받아서 리レー 서버와 연결함. 그러니까, 사용자는 별도로 토큰을 발급 받아서 관리할 필요가 없단다.

### 밈(meme) 및 노인네/동네 형 컨셉

그럼, 이제부터는 리レー 서버를 보호해 볼 시간임 ㅋ. 그리고, 이 기능은 앞으로도 계속 개선될 거야. 예를 들면, 토큰의 Scope를 지정해서 Endpoint마다 다른 권한을 부여할 수 있게 되고, 리レー 서버의 접근을 개별 Endpoint마다 제어할 수 있게 된단다. 그러니까, 앞으로도 계속 지켜보셈 ㅋ.
