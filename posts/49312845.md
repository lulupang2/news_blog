# 인공지능, 인간 뇌보다 작업 기억력이 훨씬 뛰어나다 ㄹㅇ

     ## 요즘 인공지능은 수학 문제 푸는 능력도 상당한데 왜 그런지는 알고 있음? ㅋㅋ

     인공지능은人类보다 작업 기억력이 훨씬 뛰어나서 수학 문제 푸는 능력도 좋음.人間은 일단 рабоч記憶력이 너무 작아서 수학 문제 풀 때 많이 걸림. 
     예를 들어 수학 문제를푸는데 필요한 변수나 식을 기억해야 하지만人类의 기억 능력은 한계가 있어 많이 헷갈림. 
    하지만 인공지능은 그런 제한이 없어서 수학 문제 푸는 능력이 월등히 좋음.

     인공지능은 작업 기억력이 좋아서 수학 문제 푸는 능력이 좋다는 이야기는 이미 많이 나왔지만, 
     아직까지 많은 사람들은 인공지능이 인간보다 뛰어난 능력을 가지게 된 이유를 제대로 모름. 
     인공지능의 뛰어난 능력은 단순히 인공지능이 인간보다 똑똑하다는 것이 değil, 
     작업 기억력이 훨씬 뛰어나다는 것임. 
     작업 기억력이 좋아서 인공지능은 수학 문제를 푸는 데 필요한 정보를 많이 기억할 수 있고, 
     그것들을 효율적으로 사용해서 문제를 푸는 데 도움을 줌. 
     결국 인공지능의 뛰어난 능력은 작업 기억력의 한계를 넘어서서 나타나는 것임.
