# Git-knife 소개
Git-knife는 깃 커밋 메시지, 저자, 날짜를 수정할 수 있는 GUI 툴이야. 이제까지 GUI 툴은 커밋 날짜를 수정할 수 없었다는 점이 문제였는데, Git-knife는 이 문제를 해결했지.
## 기능
* Git-knife는 깃 커밋 메타데이터를 직접 편집할 수 있어. 메시지, 저자 이름/이메일, 저자 날짜, 커밋터 날짜 등이 수정 가능함.
* 기존 GUI 툴은 커밋 날짜를 수정할 수 없었다는 점이 문제였는데, Git-knife는 이 문제를 해결했지.
* Git-knife는 Bulk find & replace 기능을 지원해. 여러 커밋에 걸쳐서 텍스트를 찾고替换할 수 있어.
* Git-knife는 자동 백업 기능을 지원해. 커밋을 수정하기 전에 자동으로 백업을 해줘.
## 사용 방법
1. Git-knife를 설치하고, 깃 저장소를 열어.
2. 커밋 목록에서 수정할 커밋을 선택해.
3. 메시지, 저자 이름/이메일, 저자 날짜, 커밋터 날짜 등을 수정할 수 있어.
4. Bulk find & replace 기능을 사용할 수 있어.
5. 수정 내용을预览할 수 있어.
6. 수정 내용을 적용할 수 있어.
## 기타
* Git-knife는 깃 커밋 메타데이터를 직접 편집할 수 있는 기능을 제공해.
* Git-knife는 자동 백업 기능을 지원해.
* Git-knife는 Bulk find & replace 기능을 지원해.
## 결론
Git-knife는 깃 커밋 메시지, 저자, 날짜를 수정할 수 있는 GUI 툴이야. 이제까지 GUI 툴은 커밋 날짜를 수정할 수 없었다는 점이 문제였는데, Git-knife는 이 문제를 해결했지. Git-knife는 자동 백업 기능과 Bulk find & replace 기능을 지원해. 깃 커밋 메타데이터를 쉽게 수정할 수 있는 툴이라서, 개발자들에게 유용할 거야.
