# x86 CPU에 하드웨어 백도어 있다니 ㄹㅇ 개빡침 
   요즘 CPU 보안 관련 뉴스 많지 않음? 
   이번에는 x86 CPU에 백도어가 있다는 거야 ㅋ 
   VIA C3 CPU에 문제가 있다고 하는데 이거 쓰는 시스템들은 조심해야 할 것 같앙 
   **백도어가 뭐냐면** CPU에다가 임베디드 코어 하나가 들어가 있는데 이 코어가 시스템 프로텍션을 모두 무시하고 마음대로 읽고 쓰는겨 
   보통은 커널 레벨에서만 활성화가 가능하지만 어떤 시스템은 기본으로 활성화가 되있대요... 
   **어떤 시스템이 영향을 받는지 확인하는 법** 
   1. `git clone https://github.com/xoreaxeaxeax/rosenbridge` 
   2. `cd rosenbridge/util` 
   3. `make` 
   4. `sudo modprobe msr` 
   5. `sudo ./bin/check` 
   **백도어를 닫아버리는 법** 
   1. `cd fix` 
   2. `make` 
   3. `sudo make install` 
   4. `reboot` 
   근데 이미 시스템이 공격당했으면 다시 열 수 있다니... 
   **이거 왜 이런지 요약하자면** 
   CPU 메이커들이 임베디드システム용으로 만들었던 기능이 기본으로 활성화가 된 경우가 있다고 하니깐 
   이거 보안 업체들이 찾아낸 거라고 하니까 이제부터는 안전하겠지 
   근데 CPU 보안 이런거는 모르겠고 just 쓰라는 거지...
