### 딥시크 V4 플래시 업데이트
딥시크 V4 플래시 API 공식 릴리즈가公開 베타에 진입했 븅신들아. 
API 호출 방식은 변동 없는 상황임. 모델 이름을 `deepseek-v4-flash`로 설정하면 최신 버전을 쓸 수 잔다는 점 잊지 마라 븅신아. 
에이전트 능력 개선이 대폭 이루어졌고, 벤치마크 결과가 V4 프로 프리뷰보다 훨씬 좋다 븅신들아. 
* 터미널 벤치 2.1: 82.7
* NL2Repo: 54.2
* 사이버짐: 76.7
* 딥스웨: 54.4
* 툴알톤 검증: 70.3
* 에이전트 마지막 시험: 25.2
* 자동화 벤치(공개): 25.1
* DS 벤치 풀스택: 68.7
* DS 벤치 하드: 59.6

### 업데이트 내용
공식 딥시크 V4 플래시 업데이트에서 코드 에이전트 작업의 공개 벤치마크 세트는 곧 출시될 딥시크 하네스 최소 모드를 프레임워크로 사용했 븅신들아. 
최대 노력 수준, topp=0.95, 온도=1.0으로 테스트했다는 점 잊지 마라 븅신아. 
DS 벤치 풀스택은 내부 풀스택 개발 테스트 세트이고, DS 벤치 하드는 내부 코딩 에이전트 하드 문제 테스트 세트임 븅신들아. 
공식 V4 플래시가 네이티브로レス폰스 API 포맷을 지원하고, 코덱스에 특별히 최적화되어 있 븅신들아. 
구체적인 구성은 문서를参照하라 븅신아. 
딥시크 V4 플래시 0731은 딥시크 V4 플래시 프리뷰와 동일한 모델 아키텍처와 크기를 유지하며, 리포스트 트레이닝만 수행했다는 점 잊지 마라 븅신아. 
이 업데이트에서는 딥시크 V4 플래시 API만 업그레이드했 음. 
딥시크 V4 프로 API와 앱/웹 모델은 변경되지 않았 븅신들아. 
공식 딥시크 V4 프로 릴리즈는곧 따른다 븅신들아.
