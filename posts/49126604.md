# qm - 다중 에이전트 하네스
   qm은 스타트업을 위한 다중 에이전트 Harness임ㅋㅋ 대부분의 에이전트는 개인용 어시스턴트처럼 설계돼서 회사 전체에서 쓸 때 복잡해짐ㅇㅇ qm은 각각의 고유 작업 공간에서 개별로 작업할 수 있고, 채널, 그룹 메시지, 프로젝트에서 협업도 가능함ㅋㅋ 
   ## 특징
   - 개인과 공유 공간 따로 있음 
   - 슬랙과 웹에서 쓰기 가능 
   - 관리자 통제 가능 
   - 웹앱 실행 가능 
   - 공유 기술 가능 
   - 백그라운드 작업 가능 
   ## 쓸 수 있는 기능 
   - 내부 노트, 이메일, 문서, 데이터베이스, 웹에서 정보 검색 가능 
   - 회사 지식에서 정보 검색 가능 
   - 내부 앱 빌드, 공유, 데이터 갱신 가능 
   - 글쓰기 스타일 học고, 일정으로 메일함 분류 가능 
   - 기존 저장소에서 테스트 실행, PR 열기, 모니터링 가능 
   ## 아키텍처 
   ![QM 아키텍처](https://qm.ycombinator.com/images/architecture.png)
   - 중앙 코어에서 다양한 모델과 Harness를 사용해 응답 생성 
   - Postgres로 사용자 데이터, 세션 기록, 지속 상태 관리 
   - 에이전트는 작은 툴 서피스 가지고,.execute 툴로 사용자만의 고유한 샌드박스에서 명령 실행 가능 
   - 웹 UI, 관리자 패널, 공용 포탈은 코어 HTTP API 플러그인 
   ## 보안 및 비밀
   qm은 오픈코드, 코덥스, 클라우드 코드 같은 로컬 코딩 에이전트와 비슷하게 작동함ㅋㅋ 에이전트는 작업하는 사람의 자격증명과 권한을 사용하고, 모든 작업은 감시 가능 
   ## 배포 
   qm init 명령으로 배포 레포지토리 초기화 가능 
   - npm exec --yes --package=@yc-software/qm@latest -- \ qm init . --org <slug> --target <fly-or-aws> 
   - qm은 MIT 라이센스를 따름
