### 고 언어 1.27 업데이트 내용
고 언어 1.27 버전에서 추가된 주요 기능들에 대해 알아보자.

#### 제네릭 메서드
고 언어에서는 이제 메서드도 제네릭 타입을 지원한다. 예를 들어,
```go
type Box[T any] struct{ v T }

func (b Box[T]) Map[U any](f func(T) U) Box[U] {
    return Box[U]{v: f(b.v)}
}
```
이제 `Box` 타입의 메서드 `Map`도 제네릭 타입 `U`를 지원한다.

#### 구조체 리터럴 필드 선택자
이제 구조체 리터럴에서 임베디드 필드를 직접 지정할 수 있다. 예를 들어,
```go
type Base struct { ID int }
type User struct { Base; Name string }

u := User{ID: 7, Name: "Mittens"}
fmt.Println(u.ID, u.Name)  // 7 Mittens
```
이전에는 `User{Base: Base{ID: 7}, Name: "Mittens"}`과 같이 해야했지만, 이제는 임베디드 필드 `ID`를 직접 지정할 수 있다.

#### 함수 타입 추론 일반화
고 언어의 함수 타입 추론이 더 강력해졌다. 예를 들어,
```go
func first[T any](s []T) T { return s[0] }
func last[T any](s []T) T { return s[len(s)-1] }

ops := []func([]int) int{first, last}
for _, op := range ops {
    fmt.Println(op([]int{10, 20, 30}))
}
```
이제 함수 타입 추론이 더 잘 동작한다.

#### 메모리 할당 최적화
고 언어의 메모리 할당이 더 빠르다. 특히 작은 객체 할당에 큰 개선이 있었다.

#### 고루틴 레이블
고루틴 레이블이 더 잘 작동한다. 예를 들어,
```go
ctx := context.Background()
pprof.Do(ctx, pprof.Labels("request", "42"), func(ctx context.Context) {
    buf := make([]byte, 1<<12)
    n := runtime.Stack(buf, false)
    fmt.Printf("%s", buf[:n])
})
```
이제 고루틴 레이블이 더 잘 출력된다.

#### 고루틴 누수 프로파일
고루틴 누수 프로파일링이 더 잘 동작한다. 예를 들어,
```go
func leak() {
    ch := make(chan int)
    ch <- 1 // blocks forever
}

go leak()
runtime.Gosched()
pprof.Lookup("goroutineleak").WriteTo(os.Stdout, 1)
```
이제 고루틴 누수를 더 잘検出할 수 있다.

#### 양자 컴퓨터 대응 서명
고 언어에서 양자 컴퓨터 대응 서명이 더 잘 동작한다. 예를 들어,
```go
priv, _ := mldsa.GenerateKey(mldsa.MLDSA65())
msg := []byte("victoria metrics")
sig, _ := priv.Sign(rand.Reader, msg, crypto.Hash(0))
fmt.Println("scheme: ", mldsa.MLDSA65())
fmt.Println("sig size:", mldsa.MLDSA65().SignatureSize())
fmt.Println("verified:", mldsa.Verify(priv.PublicKey(), msg, sig, nil) == nil)
```
이제 양자 컴퓨터 대응 서명이 더 잘 작동한다.

#### UUID 패키지
고 언어에서 UUID 패키지가 더 잘 동작한다. 예를 들어,
```go
a := uuid.MustParse("f81d4fae-7dec-11d0-a765-00a0c91e6bf6")
fmt.Println("parsed:", a)
fmt.Println("nil: ", uuid.Nil())
fmt.Println("max: ", uuid.Max())
```
이제 UUID 패키지가 더 잘 작동한다.

#### JSON v2 기본 사용
고 언어에서 JSON v2가 기본으로 사용된다. 예를 들어,
```go
data := struct {
    Name string
    Age  int
}{
    Name: "John",
    Age:  30,
}
json, _ := json.Marshal(data)
fmt.Println(string(json))
```
이제 JSON v2가 기본으로 사용된다.
