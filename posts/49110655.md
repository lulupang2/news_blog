# SDL_GP란?
SDL_GP란 2D 그래픽스 리얼타임 렌더링 라이브러리임. sdl3로 만든거고 성능 개좋음. sokol_gp를 sdl3로 포팅한거고 소콜은 자체적으로 리소스를 관리하는데 sdl_gp는 그런거 없음. 그래서 sdl_gp에서 리소스 관리 시스템 하나 제공함.

# 주요功能
- 이미지 생성/소멸
- 셰이더 생성/소멸
- 그래픽스 파이프라인 생성/소멸
- 페인터 설정
- 그리기
- 이미지/셰이더/파이프라인 등등

# 사용법
SDL_GPSetup으로 설정하고 SDL_GPShutdown으로 종료함. 그리려면 SDL_GPBegin으로 시작하고SDL_GPFlush로 렌더링하고 SDL_GPEnd로 끝낸다음. SDL_SubmitGPUCommandBuffer로 커멘드 버퍼를 제출하면 렌더링됨.

# 썰
저작자曰 "요즘 2D 그래픽스 리얼타임 렌더링 라이브러리 뭐 없나 생각했는데 sokol_gp가 보이고 sdl3로 포팅하기로 결정함. 그래서 만든게 sdl_gp임."
