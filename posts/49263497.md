### 압축이 뭔데? 
압축은 데이터를 줄이는 기술이야. 근데 이 기술은 Language Model과 같은 문제를 풀고 있다는게 핵심이야. 
압축에는 여러 가지 방법이 있는데, 그 중 하나가 minification이라는 거야. minification은 코드를 möglich한 작은 크기로 줄이는 거지. 예를들면 변수 이름을 짧게 만들어주거나, 공백이나 주석을 지워버리는 식이야. 
```javascript
// 원본 코드
function sumNumbers(numbers) {
    let total = 0;
    for (const number of numbers) {
        total += number;
    }
    return total;
}
// minification 이후
function sumNumbers(a){let b=0;for(let c of a)b+=c;return b;}
```
근데 이렇게 코드를작은 크기로 만들었을때도 데이터를 가능한 한 작게 하긴 어렵다고 해. 
근데 minification은 그냥 불필요한 코드를 지워버리는 거지, 데이터의 패턴을 예측해서 데이터를 줄이는게 아니야. 
### 데이터의 패턴을 예측하는 압축
데이터의 패턴을 예측하는 압축에는 여러 가지 방법이 있지만, 대표적으로 run-length encoding이라는 게 있어. 
run-length encoding은 연속된 같은 문자를 하나의 문자와 반복 횟수로 표현하는 거야. 
```markdown
// 원본 데이터
AAAAAAAAABBBBCCDAAADDDDDDDDD
// run-length encoding 이후
A9B4C2D1A3D9
```
이 तरह으로 데이터를 줄일 수 있어. 
근데 이건 압축의 가장 기본적인 예시고, 실제로 쓰이는 압축 알고리즘은 훨씬 더 복잡하고 성능이 좋은 거야. 
### 압축 알고리즘
실제로 쓰이는 압축 알고리즘에는 여러 가지 방법이 있지만, 대표적으로 gzip, Brotli라는 게 있어. 
이 압축 알고리즘에는 transform, model, entropy coder라는 세 가지组成 요소가 있어. 
- transform: 데이터를 압축하기 쉬운 형태로 변환해주는 거야. 
- model: 데이터의 패턴을 예측해서 확률을 계산해주는 거야. 
- entropy coder: 계산된 확률을 이용해서 데이터를 압축해주는 거야. 
이 drei 요소들이 함께 협력해서 데이터를 압축해. 
### 압축의 핵심은 예측
압축의 핵심은 데이터의 패턴을 예측해서 데이터를 줄이는 거야. 
이 예측은 Language Model이 쓰는 예측과 개념이 똑같다는게 핵심이야. 
Language Model은 데이터의 패턴을 맞혀서 다음 단어를 예측하려고 해. 
압축은 데이터의 패턴을 예측해서 데이터를 줄이려고 해. 
이 두 가지가 결국 같은 문제를 푸는 거야. 
### 확률과 압축
압축에서 확률은 매우 중요해. 
데이터의 패턴을 예측하기 위해서는 확률을 계산해야 해. 
이 확률을 이용해서 데이터를 압축할 수 있어. 
```markdown
// 원본 데이터
ABABAAC
// 확률 계산
A: 0.571, B: 0.286, C: 0.143
```
이 확률을 이용해서 데이터를 압축할 수 있어. 
```markdown
// 압축된 데이터
0.3876953125
```
이压縮된 데이터는 원본 데이터를 복원할 수 있어. 
```markdown
// 복원된 데이터
ABABAAC
```
이 압축과 복원 과정을 이용해서 데이터를 효율적으로 저장하고 전송할 수 있어.
